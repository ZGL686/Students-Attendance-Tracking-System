# 项目概览

Ludian（原名归录）是用户要求的 Windows 班级课堂考勤应用，面向每天登记异常考勤及学期末汇总。

已明确使用 React + Vite + Tauri，交付网页开发服务器、Windows EXE、最新版压缩包和解压目录。界面参考 Notion 官方 UI 和提供的移动课表截图，按桌面布局实现。

用户进一步要求依据更多 Notion 官方 UI 图片与数据库手册重做整体布局、色调和数据库功能，并改善字体边缘观感。

用户明确将产品更名为 Ludian，采用黑白图标；要求修复侧栏白屏、简化左上角班级入口、提供差异明显的字体和克制但清晰的交互反馈，并从全局维护公共模块及代码质量。

初版见 [[日志/2026-09-20-班级考勤初版]]，最新改造与检查结果见 [[日志/2026-09-20-Ludian交互与模块化改造]]。未经过用户验收的具体技术选型保留为候选记忆。
