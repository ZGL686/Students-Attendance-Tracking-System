# 项目概览

2026-10-19 完成 0.5.12 全应用留白修复及 Android / Windows 发行构建：补齐阅读卡片、工具条、设置及说明区域内边距，手机备份操作改为单栏，补齐数据库全选、分组及日历工具区留白。用户明确要求文字不贴边、不被圆角遮挡；具体布局选择、构建与检查范围见 [[日志/2026-10-19-Ludian全应用留白与手机备份排版修复]]。

Ludian（原名归录）是本地班级课堂考勤应用，覆盖 Windows 桌面与 Android 手机，面向日常异常考勤登记和学期末汇总。

2026-10-15 用户要求将文字清晰度修复扩展到整个应用，并强调成品美观、操作简单。主题、说明、工具条、表单和交互状态适应内置 / 自定义壁纸，无需新增设置；保留壁纸、玻璃透明度、明暗、字体和字号偏好。本轮源码、Android APK 与 Windows EXE / ZIP 统一为 0.5.11，实施自动前景与阅读底板保护，并统一阅读卡片的圆角、留白和文字层级，搜索图标与输入内容保持同一行。377 项单元与 36 项相关端到端测试通过；Android 签名与资源审计已通过，Windows 完整发行构建及最终产物核验继续记录于 [[日志/2026-10-15-Ludian全局文字自适应对比修复]]。

Android 0.5.10 根据手机截图修复底部五项导航遮挡，图标、文字与点击区域整体位于系统区域上方；保留简洁的表格自动导入。实现、验证及明确旧产物清理见 [[日志/2026-10-15-Ludian手机底部导航避让与旧产物清理]]。

2026-10-15 用户明确将手机课程导入改为已整理的 Excel / CSV 表格，删除手机内置图片 OCR，增加误选学生名单、空表或不含排课信息的提示并精简窗口文案。手机模拟器采用相同导入范围；桌面保留图片、Excel / CSV、PDF 本地导入。0.5.9 的实现及验证见 [[日志/2026-10-15-Ludian手机表格导入与错文件提示]]。

已明确使用 React + Vite + Tauri，交付网页开发服务器、Windows EXE、最新版压缩包和解压目录。界面参考 Notion 官方 UI 和提供的移动课表截图，按桌面布局实现。

用户进一步要求依据更多 Notion 官方 UI 图片与数据库手册重做整体布局、色调和数据库功能，并改善字体边缘观感。

用户明确将产品更名为 Ludian，采用黑白图标；要求修复侧栏白屏、简化左上角班级入口、提供差异明显的字体和克制但清晰的交互反馈，并从全局维护公共模块及代码质量。

初版见 [[日志/2026-09-20-班级考勤初版]]，最新改造与检查结果见 [[日志/2026-09-20-Ludian交互与模块化改造]]。未经过用户验收的具体技术选型保留为候选记忆。

2026-09-27 用户明确取消登录和云端数据库 / 云主题方案，要求视觉主题全部内置并增加数量；本版范围为 18 套主题和经典外观，涵盖宫崎骏风、二次元、国漫及扩展风格。用户批准图片、Excel / CSV、PDF 的本地课表导入与预览核对流程，继续保护旧数据、历史考勤和原外观偏好。实现与测试见 [[日志/2026-09-27-Ludian内置主题与离线课表导入]]；具体依赖、主题 schema、偏好迁移和导入解析策略保持 proposed，正式发布状态以验收记录为准。

2026-09-28 用户确认扩展为 Android 离线 APK：本地 SQLite/schema 3、18 套内置主题、手动 JSON 迁移。后续要求重新适配手机界面并尽可能恢复桌面完整功能，取代手机只读范围。工具链和签名已配置，APK 已产出；新增编辑、导入、完整数据库及手机导航，原生设备验收仍待完成，见 [[日志/2026-09-30-Ludian手机完整交互改造]]。
