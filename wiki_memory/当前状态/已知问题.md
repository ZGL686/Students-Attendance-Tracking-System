# 已知问题与边界

- 完整快照保留全部历史，长期使用会增加磁盘占用，初版不自动清理。
- 同机快照不能抵御硬盘故障，仍需外部 JSON 备份；损坏数据库不自动覆盖。
- 浏览器与桌面数据独立，需要通过 JSON 迁移。
- 部分晚间作息与未排时段的实践课需核对。
- Windows 应用未商业签名，需要系统 WebView2。
- schema 2 可由新版从旧数据升级；0.1.0 无法读取新版保存后的数据，会拒绝加载。旧快照仍保留。
- 学生和考勤为固定数据库；未包含任意数据库 / 自定义关联、公式、时间轴、嵌套筛选和在线协作。已有自定义属性不改类型。
- 浏览器和桌面实测已加载内置字体；实际物理屏幕上的字形边缘仍需用户验收。
- 外观偏好保存在设备上，不进入考勤备份；系统字体随机器而异，手写字体仅常规字重，粗体由浏览器合成。完整离线字体使 0.3.0 ZIP 约 34.7 MB。
- 依赖审计报告 ExcelJS 的间接 uuid 库中等风险；所读 ExcelJS 源码只调用 v4，不涉及报告中的 v3/v5/v6 外部缓冲区。本轮不是完整安全审计。
- Android 源码和 Android 专用前端构建已完成；当前环境缺少 JDK/Android Studio、SDK/NDK 和 Rust Android targets，尚未产出或签名 APK，也未完成模拟器 / 实体机验证。首次 release 前须决定并妥善保存长期更新用 Keystore。
