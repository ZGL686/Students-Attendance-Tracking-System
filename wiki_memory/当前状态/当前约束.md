# 当前约束

以下来自用户需求及本轮明确回复：

- React + Vite + Tauri，网页实时开发和 Windows 桌面运行。
- 开学日期随时可改，课表按北京时间推进教学周。
- +1 登记具体时间、课程，明细可人工修改。
- 请假、旷课、迟到、早退等类型；Markdown、Excel 汇总。
- 新名单、新工作台、完整备份恢复；版本升级不能覆盖数据。
- dist/ 中保留最新压缩包与解压目录。
- 采用提供的工程记忆模板，每次完整修改必须提交推送。
- 早期默认界面否定了初版绿色主题，要求参考 Notion 官方 UI 图片与手册改造布局和数据库交互，并改善文字锯齿；新增可选视觉风格遵循后续明确需求。
- 产品名 Ludian，黑白 Notion 风格图标；更名仍需兼容原数据。
- 左上角只保留单一班级入口；字体选项需要风格差异明显，微交互需要清晰但克制。
- 从全局和系统出发维护代码质量、公共模块与可维护性，避免冗余及逐处孤立实现。

数据保存候选实现见 [[决策/ADR-001-本地数据保存]]。记忆中不记录真实姓名、学号和考勤明细。

- 0.4.0 明确整改：工作台可管理编辑和删除；主题包含跟随系统、浅色、深色；考勤工作台既能登记加号，也能撤销减号，操作符合日常使用习惯。
- 2026-09-27 明确取消登录和云端数据库 / 云主题方案，不要求用户注册、开通云服务或连接账户；主题全部内置，增加至本版 18 套及经典外观，保持离线可用。
- 新增视觉主题覆盖宫崎骏风、二次元、国漫及更多风格；允许先预览再应用，原明暗、字体、字号和动效偏好继续保留。
- 批准图片、Excel / CSV、PDF 的本地课表导入与预览核对流程；课程识别后可修正再保存，继续保护原课表、学生和历史考勤，不因取消或识别失败改写现有数据。

本轮需求来源见 [[日志/2026-09-27-Ludian内置主题与离线课表导入]]。依赖选择、解析算法、主题定义格式和迁移实现属于 proposed 选型，不能据此认定用户已验收。

- 2026-09-28 用户确认 Android APK 优先方案：Android 7.0+、离线运行、本地 SQLite 与 schema 3、18 套内置主题；通过未加密 JSON 在 Windows 与手机之间人工迁移。首版手机仅查看课表和学生、登记 / 撤销考勤、查看历史及备份，不做云同步、手机名单 / 课程编辑、OCR 导入或微信小程序。迁移规则及尚未完成的原生构建见 [[日志/2026-09-28-Ludian安卓离线版]]。

- 2026-09-30 后续明确需求取代上一条中的手机只读范围：重新排版以符合手机操作习惯和屏幕，尽可能恢复桌面所有交互与功能；用户授权补齐工具并交付可安装 APK。仍保持离线、无登录 / 云端 / 微信小程序，资料兼容与签名连续性不变。实现和未完成验收见 [[日志/2026-09-30-Ludian手机完整交互改造]]。
