# 当前约束

2026-10-19 用户要求修复全应用文字贴边问题。卡片、工具条和说明文字应保留统一内边距，避免圆角遮字，文字与按钮保持清晰留白。该要求见 [[日志/2026-10-19-Ludian全应用留白与手机备份排版修复]]。

2026-10-15 用户进一步要求全应用文字在不同明暗主题及任意内置 / 自定义壁纸上清晰可读，不能仅修底部导航，并强调最终成品美观。说明、工具条、表单、通知、提示及禁用 / 已撤销状态应一并保护；自动处理，不增加用户配置。保留原壁纸、玻璃透明度、明暗、字体与字号偏好，文字阅读区域可自动加实底板；阅读卡片保持统一圆角、留白与文字层级，搜索图标内联。源码、Android 和 Windows 本轮统一更新为 0.5.11，Windows 通过完整发行流程构建并核对解压版与 ZIP。该需求为明确约束，具体前景调整算法、对比阈值及技术选型仍保留为 proposed，见 [[日志/2026-10-15-Ludian全局文字自适应对比修复]]。

2026-10-15 用户要求手机底部五项导航的图标与文字整体上移，完整避开系统三按钮 / 手势区域，继续保持操作简洁。旧版本安装包和无用测试产物按明确路径清理，保留最新发行物、已核对课表、个人资料、考勤 / 备份、签名及工具链；不清空整个本地数据目录或工程记忆，见 [[日志/2026-10-15-Ludian手机底部导航避让与旧产物清理]]。

2026-10-15 用户再次强调使用者操作应简单清楚，避免复杂与多余步骤。课程导入保持“选择文件 → 自动追加保存”，错误时直接说明原因；手动补录收起备用，不要求安装插件或逐项确认。

2026-10-15 用户明确取消手机内置图片 OCR，手机与手机模拟器改用已整理、核对的 Excel / CSV 课表直接导入，无需额外识别插件。导入界面精简文案，误选学生名单要明确引导到学生页；文件没有课程信息、空表、只有课程目录或缺少排课字段均需具体提示。该要求取代此前手机多图 / PDF OCR 的范围，桌面仍保留图片、Excel / CSV、PDF。已有数据、自动追加及仅保存成功才提示成功的约束继续有效，见 [[日志/2026-10-15-Ludian手机表格导入与错文件提示]]。

2026-10-12 用户进一步要求：多张目录图、课表图及文件一起选择，识别内容形成并集后一次导入全部有效安排；提高本地识别速度和准确率，修复进度反复回退造成的卡住观感。仍保留重复 / 冲突提示、目录暂存、离线处理和已有数据。实现与验证见 [[日志/2026-10-12-Ludian批量并集导入与识别进度提速]]。

2026-10-12 用户确认：课程目录与课表图片同时导入，选择顺序不限；目录只作为本次导入的临时参考，缺少课程周次时使用保存事务中最新的整个学期，首先在手机模拟器交付验收。完整安排直接追加并一次保存，重复、冲突和不可靠条目明确提示，低分教师或教室留空。实现与验证见 [[日志/2026-10-12-Ludian多图目录联用与课程块识别修复]]。

2026-10-12 用户明确要求：删除手机完整数据库底部成组的“不计算”列计算下拉控件。实现与验证见 [[日志/2026-10-12-Ludian手机数据库移除列计算区]]。

2026-10-12 用户明确要求：手机模拟器不展示默认示例同学，新预览名单为空，保留手动录入 / 导入的学生。实现与验证见 [[日志/2026-10-12-Ludian模拟器取消示例学生]]。

2026-10-09 最新交互要求：手机底部导航需避开系统功能区并保持不透明，图标和文字完整可读；考勤、学生、课程和记录的数据表格 / 卡片必须保持不透明；课表图片、Excel、CSV、PDF 使用顶部星期列、左侧节次行和课程格这一统一版式自动识别。网格课表未标周次时按当前学期全周保存并提示；显式周次照常使用。导入识别课程后直接保存，跳过检查修改和确认步骤。实现见 [[日志/2026-10-09-Ludian手机导航可读性与课表网格识别]]。

以下来自用户需求及本轮明确回复：

- React + Vite + Tauri，网页实时开发和 Windows 桌面运行。
- 开学日期随时可改，课表按北京时间推进教学周。
- +1 登记具体时间、课程，明细可人工修改。
- 请假、旷课、迟到、早退等类型；Markdown、Excel 汇总。
- 新名单、新工作台、完整备份恢复；版本升级不能覆盖数据。
- dist/ 中保留最新压缩包与解压目录。
- 采用提供的工程记忆模板，每次完整修改必须提交推送。
- 早期默认界面否定了初版绿色主题，要求参考 Notion 官方 UI 图片与手册改造布局和数据库交互，并改善文字锯齿；新增可选视觉风格遵循后续明确需求。
- 产品名 Ludian，黑白 Notion 风格图标；更名仍需兼容原数据。
- 左上角只保留单一班级入口；字体选项需要风格差异明显，微交互需要清晰但克制。
- 从全局和系统出发维护代码质量、公共模块与可维护性，避免冗余及逐处孤立实现。

数据保存候选实现见 [[决策/ADR-001-本地数据保存]]。记忆中不记录真实姓名、学号和考勤明细。

- 0.4.0 明确整改：工作台可管理编辑和删除；主题包含跟随系统、浅色、深色；考勤工作台既能登记加号，也能撤销减号，操作符合日常使用习惯。
- 2026-09-27 明确取消登录和云端数据库 / 云主题方案，不要求用户注册、开通云服务或连接账户；主题全部内置，增加至本版 18 套及经典外观，保持离线可用。
- 新增视觉主题覆盖宫崎骏风、二次元、国漫及更多风格；允许先预览再应用，原明暗、字体、字号和动效偏好继续保留。
- 批准图片、Excel / CSV、PDF 的本地课表导入与预览核对流程；课程识别后可修正再保存，继续保护原课表、学生和历史考勤，不因取消或识别失败改写现有数据。

本轮需求来源见 [[日志/2026-09-27-Ludian内置主题与离线课表导入]]。依赖选择、解析算法、主题定义格式和迁移实现属于 proposed 选型，不能据此认定用户已验收。

- 2026-09-28 用户确认 Android APK 优先方案：Android 7.0+、离线运行、本地 SQLite 与 schema 3、18 套内置主题；通过未加密 JSON 在 Windows 与手机之间人工迁移。首版手机仅查看课表和学生、登记 / 撤销考勤、查看历史及备份，不做云同步、手机名单 / 课程编辑、OCR 导入或微信小程序。迁移规则及尚未完成的原生构建见 [[日志/2026-09-28-Ludian安卓离线版]]。

- 2026-09-30 后续明确需求取代上一条中的手机只读范围：重新排版以符合手机操作习惯和屏幕，尽可能恢复桌面所有交互与功能；用户授权补齐工具并交付可安装 APK。仍保持离线、无登录 / 云端 / 微信小程序，资料兼容与签名连续性不变。实现和未完成验收见 [[日志/2026-09-30-Ludian手机完整交互改造]]。

- 2026-10-03 用户明确选择为 0.5.3 创建新 Android 发布签名，替代上述签名连续性要求：旧签名版本先将完整 JSON 备份保存到应用外，再卸载、安装新版并导入备份；包名和数据兼容要求不变。后续发布复用本次新签名，签名资料只保存在本机并由用户另行独立备份。交付与检查范围见 [[日志/2026-10-03-Ludian-0.5.3本地安装包发布.md]]。
