# Ludian 0.5.5 Android APK 构建

- 目标：为当前最新 Android 发布代码构建签名通用 APK。
- 来源：`origin/codex/mobile-ux-wallpaper-20261003`，提交 `8465b26`，版本 0.5.5；`main` 当时仍为 0.5.1。当前工作分支跟踪该发布分支。
- 复用本机 Android SDK 36、NDK 29、JDK 17 和既有发布签名；补装 ARM64 / ARMv7 Rust targets 与 `cargo-ndk`。
- 运行 `npm run android:init` 与 `npm run android:build`，产出 universal release APK；离线 OCR/PDF 资源已随构建准备。
- 使用本机签名脚本对 APK 执行 16 KB 对齐、签名和验证，并将 APK 与版本清单放入 `dist/`。签名资料不进入仓库或安装包。
- 输出为 `dist/Ludian-Android-universal.apk` 与 `dist/android-version.json`，包名 `cn.guilu.attendance`，versionCode `5005`，最低 Android 7.0，包含 `arm64-v8a` 和 `armeabi-v7a`。
- `apksigner verify`、签名证书一致性、16 KB 对齐及 APK 清单检查均通过；APK SHA-256：`1db01a34d426cce76aba39fbcb27d153bdde42ece08addfb7783ce78cc76dfc7`。
- `nativeDeviceTested` 为 false；本轮未在模拟器或实体手机运行验收。APK 延续 0.5.5 发布签名；更早签名版本的迁移步骤见 [[日志/2026-10-03-Ludian-0.5.3本地安装包发布.md]]。
