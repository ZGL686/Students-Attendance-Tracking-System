# Ludian 主题切换与手机数据直显

- 目标：统一自定义与内置主题；按用户视频消除手机学生数据库的横向滑动；简化课程导入；在学生页直接导入名单，交付 0.5.4 安装包。

## 用户确认

- 每次完整对话的工程更改都必须提交并推送到指定 GitHub 仓库，继续遵守项目根 AGENTS.md。
- 自定义图片主题与 18 套内置主题互相切换，玻璃透明度使当前主题更明显。
- 视频中“完整数据库”的数据列需要左滑才能看到；用户要求直接看到数据。
- 经用户明确澄清，课程导入仍需要自动识别成结构化课程，然后直接保存；跳过修改及确认步骤，不能解释为只保存原始附件。
- 学生页面同时保留手动添加及名单导入。

## 实现

- `src/preferences/` 与 `src/features/themes/ThemeGallery.tsx`：统一主题列表加入自定义主题，切换内置主题时保留自定义图片但不叠加；旧壁纸偏好迁移为当前自定义主题。玻璃透明度统一作用于选中的背景，支持 0–70%，控制放在主题列表上方。
- `src/features/database/MobileDatabaseRows.tsx` 与 `src/styles/mobile-data.css`：手机表格视图改为纵向字段卡片，显示当前视图全部可见属性，保留字段编辑、查看详情、批量选择及列计算。手机看板和列表也按屏幕宽度换行。学生便捷列表直接显示各类异常次数。
- `src/features/timetable-import/`：图片和文档独立入口，选定后处理全部工作表 / 页面并自动追加课程，不再显示草稿修正和确认页。事务内以最新课表去重、校验冲突，无法导入的条目和页面明确提示；识别期间可取消，保存期间阻止关闭。
- `src/features/database/ImportStudents.tsx`：桌面和手机学生页共用名单导入；Excel 第一工作表或 UTF-8 CSV，按学号去重。同号异名保留现有资料并提示；文件解析错误不写入，目标工作台切换后拒绝保存。
- 版本统一更新至 0.5.4，补充使用说明。远程旧 `package-lock.json` 无法按 UTF-8 解码，本次使用本地有效锁文件恢复并同步应用版本。
