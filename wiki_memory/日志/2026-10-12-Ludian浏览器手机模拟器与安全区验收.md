# Ludian 浏览器手机模拟器与安全区验收

## 目标与已确认需求

- 启动浏览器本地开发服务器，提供可操作的手机网页模拟器，默认展示课程表工作台。
- 手机参考图为 REDMI Turbo 4 Pro，6.83 英寸、1280×2772、HyperOS 2，底部使用三按钮系统导航。
- 五项应用导航从左到右为课表、考勤、学生、记录、备份；图标与文字完整可见，和系统手势条或返回按钮区域分开。
- 背景使用浅淡国风山水，界面简约，底部元素不裁切。

## 实现

- `phone-simulator.html` 和 `src/simulator/`：模拟器控制台、手机外框、系统状态栏与底部区域；iframe 接入真实应用，支持尺寸调整、横竖屏、三按钮 / 手势、自动适应 / 100% 和刷新。
- 默认以 400×866 CSS px 保留参考屏幕比例，顶部模拟 30px，三按钮底部区域 48px，手势区域 24px。CSS 尺寸和系统区域属于浏览器预览参数，并非测得的设备原生密度。
- 窄宿主浏览器默认收起控制，自动适应显示整台手机；100% 模式通过安全居中和滚动保留设备顶部、左侧与底部的可达性。
- `phone-preview.html`、`src/simulator/preview.ts`：浅色“水墨江南”主题与虚构课程、学生。只有独立预览数据库为空时初始化演示数据，刷新保留修改。
- `src/browserEnvironment.ts`：独立 IndexedDB 名称、外观与旧外观偏好键、Android 首次导入标记；普通网页和 Tauri 的已有存储标识继续使用原值。
- `src/app/bootstrap.tsx`：普通应用与预览共用挂载逻辑；`AppProvider` 支持显式传入演示初始化函数。事务、乐观版本检查及持久化成功后的反馈保持原逻辑。
- 共享 CSS 变量将真实 `env(safe-area-inset-bottom)` 与模拟边距取最大值。导航额外预留 6px，图标与双字文字不再使用裁切规则；通知、弹窗和详情使用同一安全区。
- 复用现有 `ink-jiangnan.webp`，没有新增外部素材；README 增加启动与操作说明，并校正现有版本和导入描述。

## 验证

- Vite 在 `127.0.0.1:15473` 运行；模拟器入口 `/phone-simulator.html` 返回 HTTP 200。实际浏览器已检查默认课程表、三按钮及手势显示，源码修改通过热更新生效。
- `npm run check` 通过：ESLint、92 个模块的架构边界、Prettier、TypeScript。
- `npm test` 通过：9 个测试文件、91 项测试。
- `npm run build` 通过，正式网页仍以普通应用入口构建，不包含演示 HTML 入口。
- 21 项端到端验收通过：11 项手机模拟器、3 项正常手机工作流、7 项应用外壳回归。
- 模拟器测量五个按钮及其 SVG、文字的完整矩形边界与文本溢出，确认全部位于系统区域上方，且保留至少 5px 额外间隔。
- 覆盖 320 / 360 / 400 / 430px、横屏、视口高度变化、三按钮 48px / 手势 24px、480×720 窄宿主、100% 滚动以及五页面实际导航。
- 虚构学生新增后重载仍存在，普通浏览器数据库中的合成快照和外观偏好保持原字节，预览继续使用水墨浅色主题。
- 截图、测试结果、演示数据库和个人发行文件均位于忽略目录，不提交 Git；未触碰真实学生资料或 SQLite 数据库。

## 结果与待确认长期记忆

- 已交付本地热更新服务器与可操作的手机模拟器，底部五项导航和模拟系统区域分离。
- 默认 400×866、30px / 48px / 24px 参数是本轮预览选型；真实设备 CSS 视口和原生安全区仍需实机测量，不提升为已确认长期事实。
- 浏览器系统栏为布局占位，未将浏览器验收等同于 Android APK 实机验收。
