# Ludian 手机数据库移除列计算区

## 目标与已确认需求

- 用户通过考勤记录页面截图要求删除成组显示的“不计算”下拉框。
- 该区域属于手机完整数据库的列计算设置，统一从学生和记录页面移除。

## 实现

- `MobileDatabaseRows.tsx` 删除完整列计算 JSX 区域及不再使用的导入、视图解构。
- `mobile-data.css` 删除计算区域专用样式，避免遗留空白容器。
- 记录卡片后直接接续新建记录入口及页脚；现有属性展示、选择、编辑和新建操作保留。
- 桌面表格仍使用独立计算栏；本轮无存储写入或数据迁移，不清空已保存视图、学生、考勤或计算设置。
- 更新使用说明，明确列计算栏用于桌面表格；已确认手机移除要求记录到当前约束。

## 验证

- `npm run check` 通过：ESLint、92 个模块架构边界、Prettier、TypeScript。
- `npm test` 通过：10 个测试文件、95 项测试。
- `npm run build` 通过；原有依赖注释和字体路径提示不阻止构建。
- 10 项端到端检查通过：6 项桌面数据库、1 项手机完整数据库专项、3 项不同宽度手机工作流。
- 新增专项使用全新浏览器上下文与虚构学生、考勤快照；两种手机完整数据库均无计算容器、列计算下拉框或“不计算”文本，已有计算配置不触发手机显示，正常属性及编辑、新建入口可用。
- 当前手机模拟器的考勤记录页已通过热更新移除该区；截图和测试产物位于忽略目录，不提交 Git。未自动测试真实用户数据。

## 结果与待确认长期记忆

- 手机完整数据库取消底部列计算区域，源码与开发预览已更新。
- 本轮未重新生成 Windows EXE 或 Android APK；实体设备验证仍以实际安装版本为准。
- 无新增待确认长期技术选型。
