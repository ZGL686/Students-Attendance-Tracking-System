# Ludian 全应用留白与手机备份排版修复

## 需求与原因

用户反馈手机备份页及其他页面文字贴边、被圆角遮挡，要求全应用统一修正。此前阅读底板覆盖多个页面容器，但部分容器没有配套内边距；手机备份区仍为两栏，标题、正文和按钮因此拥挤。

## 实现

- 源码、Android APK 与 Windows EXE / ZIP 更新为 0.5.12。
- 公共阅读内边距使用 `--reading-panel-padding`，本轮实现为桌面 20px、手机 16px；补齐设置面板、工具条、说明、统计卡片与课表工具区。已有表格、数据卡片及弹窗继续管理自身间距，避免重复内缩。
- 备份导出、恢复、数据位置与快照各自持有完整内边距；手机备份操作改为单栏，图标左对齐，保存状态放在正文下方。长文字可换行，按钮宽度不超过卡片。
- 降低公共阅读背景选择器权重，使备份、统计的纯布局容器能够透明显示卡片间隙，保留主题壁纸与原有对比保护。
- 补齐手机数据库全选、分组、列表和日历工具区留白；统计标题支持长文字换行。
- 主要修改位于 `src/styles/tokens.css`、`readability.css`、`settings.css`、`mobile-workflows.css`、`mobile-data.css`。业务 schema 3、存储标识、导入事务和原生系统栏逻辑未改动。
- README、使用说明、Android 构建说明与当前状态同步；用户明确的全局留白要求记录为约束，具体单栏与像素值属于本轮实现选择。

## 检查范围

- `npm run check` 通过 ESLint、114 模块边界与循环检查、Prettier、TypeScript。本轮未新增或运行单元、端到端、Cargo 测试套件，不沿用旧版测试数量作为本版证据。
- 使用独立浏览器上下文和虚构资料，查看七个主要页面及完整数据库、外观和备份位置区域。覆盖 412px 手机、360px 窄屏、915px 横屏及 1280px 桌面；深色壁纸 / 经典浅色与 20px 基础文本压力画面均已查看。28 个主页面状态没有浏览器页面错误或整体横向溢出，另保留分区域截图，共 42 张。
- 最终 Windows 解压版在全新虚构 SQLite 与独立 WebView2 目录启动；先核对实际数据库位置与浏览器进程目录，再查看备份、学期设置、外观和汇总。四张实际运行截图已目检；页面、控制台错误与观察到的外部请求均为空，自有进程已关闭。未操作真实学生、考勤或个人数据库。
- Android 构建成功，实际 APK 每个 ABI 的 35 个资源与 1 个 HTML 对应当前前端，包含最终数据库留白样式；没有 OCR / PDF 离线资源或旧 Worker。签名、版本、16 KB ZIP 对齐和 ELF LOAD 对齐通过，原生 Insets 回调及计算路径保留。
- 最终重建复用本轮初始构建的 R8 mapping：DEX 与 mapping 的 map-id `b55b00f`、R8 `8.11.18`、min API 24 内容关联一致。保留原审计守卫，并单独核对最终 APK、双架构库及前端入口均晚于最终重建起点，未通过改写时间戳规避检查。
- 诊断脚本、截图与报告仅在 `.local/ui-spacing-0512/`、`.local/apk-release-0512/`，不提交 Git。
