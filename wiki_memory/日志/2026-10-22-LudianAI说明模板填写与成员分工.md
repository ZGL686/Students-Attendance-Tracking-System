# Ludian AI说明模板填写与成员分工

## 实现与交付

- 用户提供官方《人工智能工具使用情况说明》DOCX 模板，要求根据 Ludian 完成，并明确三名成员分别承担创意与细节修改、技术指导与总体框架、最终验收与材料收集；工具为 WorkBuddy、DeepSeek。
- 按用户提供的分工整理贡献表述，不推定成员属于指导教师或具体学生身份，不将技术指导夸写为全部代码开发，不虚构工具版本、代码贡献比例或授权状态。成员姓名只保留在本地署名文件，不记录到 Git 日志。
- 附件模板与本会话已核对的官方参考模板 SHA-256 相同。删除填写指导、示例及不适用资源样表，保留八部分、四个已填写表格及一个代表性过程，压缩为两页。
- 署名版包含用户提供的成员姓名与对应职责；另提供匿名评审版，保留相同贡献内容、移除成员姓名，便于按模板匿名要求提交。既有一页说明、作品介绍和用户原附件均未修改。
- 说明范围为应用开发、界面调整和文字整理，图片等其他素材的来源、生成与许可仍需在相应资源清单如实披露。
- 交付目录为 `dist/Ludian-AI使用说明-2026/模板填写版/`。署名版 SHA-256 为 `b86a64b029eaa9b7f6ebe5f280519f0abe9615cdfec580173e777d517ecaa890`；匿名评审版 SHA-256 为 `b77b7dc8c7ef6f56864c88da3ce2c020e33ee73f451f90397488cfc6ba127d0d`。个人材料、生成脚本和检查产物仅本地忽略目录保存。

## 验证

- bundled Python 读回确认两份输出均有八个部分、四个表格、两个指定工具；署名版逐项核对分工，匿名版扫描 XML 确认不含成员姓名。源模板未改，每份输出保留 30 个非编辑包部件的原始字节。
- WPS 后台只读打开，确认两份文档各两页；bundled Poppler 回渲后检查全部四页，未见裁切、乱码、表格拆行或页码错误。
- `npm run check` 通过 ESLint、114 模块边界与循环检查、Prettier、TypeScript；本轮未修改应用源码或业务数据，未新增应用功能测试。
