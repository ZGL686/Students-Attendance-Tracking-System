# Ludian 简约教育风参赛海报

## 需求与实现

- 用户为 2026 年第十四届全国大学生数字媒体科技作品及创意竞赛制作 Ludian 移动应用海报，要求必须包含移动版 Logo，整体简约、美观、有教育应用气质；明确选择 A3 竖版。
- 采用米白、墨黑与低饱和鼠尾草绿，保留黑白纸张方块与 L 标识、Ludian 字标和清晰留白。主标题为“让课堂管理，更从容。”，四项说明分别对应课表、考勤、汇总与本地备份。
- 从当前 Android 图标资源确认移动版 Logo，并核对源码与使用说明中的产品能力；不宣传云同步、手机 OCR / PDF 导入或自动出勤率。
- 初稿使用隔离 Edge 上下文中的虚构演示班课表作为视觉参考，随后用户明确提供自己的截图并要求替换。定稿手机屏幕改为该截图中的工作台、水墨壁纸、整周课表及 Android 状态栏和系统按键，保留其余海报布局、文案与配色。
- 通过 imagegen 内置工具生成并局部替换屏幕，手机画面属于基于所供截图的合成展示，不表述为逐像素原样嵌入。
- 以 ReportLab 等比例导出单页 A3 PDF，并保留初始与修改提示词于本地制作说明。未更改应用源码、业务数据、版本或既有安装包。

## 检查与交付

- 初稿演示捕获使用独立浏览器数据、空名单保护及虚构学生课程，界面无页面错误与整体横向溢出；自有浏览器与 Vite 服务已关闭。未读取或修改真实数据库。
- 定稿目检比赛名、届次、Logo、中文标题、功能文案与新截图内容；无明显文字裁切。PDF 以 Poppler 回渲后再次目检，画面与定稿一致。
- PNG 为 1055 × 1491 像素；PDF 实际页面为 297 × 420 mm、1 页，未裁切或重采样。沿用原位图时约 90 ppi，不将其描述为 300 dpi 印刷稿。
- `npm run check` 通过 ESLint、114 模块边界与循环检查、Prettier、TypeScript；本轮未新增或运行应用功能测试套件。
- 最终交付位于 `dist/Ludian-海报-2026/`：`Ludian-2026-A3.png`、`Ludian-2026-A3.pdf` 与 `制作说明.txt`。PNG SHA-256 为 `0890289ec9677dcbb516ed054fe5891ae535168439abe1cf30e4eb13842bb420`，PDF 为 `7b0eaa22833bab4a41a4742354a4dd64f036f0f1e7d481b0e03fad210844d80d`。
- 海报、用户截图、虚构演示截图、生成提示词、脚本与检查报告仅本地保存于 Git 忽略目录；Git 仅提交本轮日志与索引。
