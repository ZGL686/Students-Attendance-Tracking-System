# Ludian 0.5.6 源码克隆与本地安装包

## 目标与结果

- 按用户要求从正式仓库 `ZGL686/Students-Attendance-Tracking-System` 克隆源码，生成最新 Windows EXE、ZIP 和 Android APK。
- 远端默认分支 `main` 仍为 0.5.1；本轮应用源码来自最新功能分支 `codex/mobile-ux-wallpaper-20261003`，提交 `b5e97e9`，版本为 0.5.6。
- 既有工作副本及其未推送提交保留。本轮在新工作副本构建，使用 `dist/` 作为本地交付目录。

## 仓库修改

- `package.json`：批准锁文件中的 `esbuild@0.28.2` 安装脚本，使 npm 11 安装后可正常构建。
- `tests/preferences.test.ts`：更新已实现的外观迁移标记预期，补充旧壁纸迁移后切换回内置主题的回归检查。
- `tests/timetable-import.test.ts`：更新空课表识别预期，检查明确报错而不凭空生成课程，与自动导入需求保持一致。
- 本日志与工作日志索引记录本轮发布检查。现有 `docs/使用说明.md` 已为 0.5.6，随 Windows 包一起交付。
- SDK、JDK、Gradle 缓存、签名资料、Android 生成工程、个人发行文件和隔离测试数据库均不提交 Git。

## 构建与验证

- `npm ci`、`npm run release`、`npm run android:init`、`npm run android:build` 完成。
- `npm run check` 全部通过；架构检查覆盖 86 个模块，无依赖环。
- 首次单元测试发现 6 个旧预期未更新；核对当前代码与已确认需求后修正测试，最终 9 个测试文件、91 项测试全部通过。应用功能源码没有修改。
- Windows 解压版 EXE 与 ZIP 内 EXE 的 SHA-256 一致，文件版本和产品版本均为 0.5.6；使用说明、字体许可证与第三方声明齐全。
- Windows 启动检查使用全新且已校验的数据库与 WebView2 目录。进程创建了隔离 SQLite 数据库后以代码 0 退出；仅确认初始化路径，未认定完整界面运行验收通过，也未访问真实考勤数据。
- Android 版本 0.5.6 / versionCode 5006，包名 `cn.guilu.attendance`，最低 API 24、目标 API 36，包含 ARM64 与 ARMv7。
- 最终 APK 的 v2/v3 签名通过，证书与既有 0.5.5 包一致；ZIP 16 KB 对齐通过，最终 APK 内 ARM64 ELF LOAD 段对齐为 `0x4000`。
- Android 生成工程配置使用本地 Gradle 缓存、Maven 镜像和原签名；Kotlin 跨盘增量缓存错误自动回退后完成构建，并关闭生成工程的增量编译以便后续使用。
- 安装包没有包含个人名单种子；未进行实体手机安装或完整界面验收。
