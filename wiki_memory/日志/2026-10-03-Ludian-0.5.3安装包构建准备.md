# 2026-10-03｜Ludian 0.5.3 安装包构建准备

- 目标：按用户要求更新本地 `dist` 中的 Windows EXE 与 Android APK，使其包含最新手机课表、导入、记录表格和壁纸改动。
- 检查发现：本地 EXE 为 0.5.0，本地 APK 元数据标为 0.5.2，而新功能源码分支原标为 0.5.1。为避免 Android 覆盖安装版本倒退，源码发行版本已提升至 0.5.3，versionCode 预期为 5003。

## 已完成

- 同步更新 `package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 和 `src-tauri/tauri.conf.json` 的应用版本。
- 更新 README、使用说明和 Android 构建说明中的当前版本信息。
- 原功能代码的 ESLint、架构、格式、TypeScript 检查及 Vite 前端生产构建已通过；本轮版本准备未改变业务代码。

## 阻塞与下一步

- 当前 Windows 主机没有 Rust / Cargo、MSVC / Visual Studio 构建工具、JDK、Android SDK / NDK，也没有可用 WSL 发行版，因此无法生成 Tauri EXE 或 APK。
- 在 `D:/dist` 和当前用户目录均未找到 APK 发布 keystore。现有 APK 的签名证书指纹为 `79ca1a91c812011a323d5f2fcddd7ab464bf24f66d0f4da7d1b6a65fd1fe3335`；必须使用匹配的私钥签名，才能让已安装版本覆盖更新。
- 等待用户恢复原构建环境，或提供原生工具链与签名 keystore 的本机路径；收到后再构建 0.5.3 EXE / APK、更新 `dist` 及 APK 元数据，并核对签名和 SHA-256。不得用新密钥签成无法覆盖已有 APK 的安装包。
- 在安装包生成并验收前，本地 EXE、APK 和 ZIP 保持原样；本日志保持 active。

## 待确认长期记忆

- 尚无新的长期决策；本次版本号选择服务于高于现有 0.5.2 APK 的升级包。
