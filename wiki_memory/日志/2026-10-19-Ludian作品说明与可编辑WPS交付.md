# Ludian 作品说明与可编辑 WPS 交付

- 目标：整理可二次修改的作品材料，覆盖明确目标用户、功能模块、业务流程、运行版本、系统说明、功能演示、界面截图、技术架构和测试说明。
- 基于当前 0.5.11 代码、使用说明、发行清单及已归档测试证据；没有更改应用功能、版本、数据库或安装包。

## 实现

- 在本地忽略的 `dist/` 生成可用 WPS 编辑的 DOCX，使用原生段落、标题、表格、超链接及可替换的嵌入图片，作者和学号等个人填写项留空。
- 说明目标用户的实际使用需求，不虚构具体职务、权限等级、访谈结果或效率提升比例。
- 整理五分钟现场功能演示脚本及同版式虚构 CSV 名单与课表，供独立演示工作台使用。
- 使用全新隔离浏览器上下文，阻断个人种子读取，捕获虚构班级的课表、登记、学生、记录、汇总、备份及手机窄屏界面；实际浏览器截图不标注为 Android 真机。
- 可运行版本采用现有 Windows 解压版 / ZIP 与 Android APK，相对路径与系统运行条件写入文档；GitHub 标明为源码入口，本机开发地址不当作公开部署网址。
- 技术架构说明界面、业务、状态保存、Tauri 原生运行与本地数据库；测试说明明确 2026年10月15日的既有验证日期与范围，保留实体 Android 手机待验证边界。

## 排版与验证

- 文档以 A4 版式、黑色分级标题、轻灰表格边框及一致的蓝灰表头组织。正文和表格可编辑，截图可替换。
- 本机技能渲染器因 Windows 捆绑环境没有 LibreOffice 而无法转换，诊断留在私有目录；改用已安装 WPS 只读打开生成的 DOCX 并导出 PDF，再用捆绑 Poppler 转逐页 PNG。只关闭本轮生成文档，不退出已有 WPS 会话，不保存或更改源 DOCX。
- 首轮检查发现一页空白与一段尾页溢出，缩短演示页附加说明并移动参考信息后重新渲染。
- 将独立分页段落改为章节标题的段前分页，消除满页时额外分页产生的空白。最终 WPS 原生渲染为 14 页，逐页 PNG 全部目检通过，无空白、短尾、截断、重叠、缺字或图片变形。
- `npm run check` 通过；没有新增或重跑应用单元、端到端或原生测试，不把文档制作当作新的应用验证。
- 文档含 120 个原生段落、10 个可编辑表格和7张可替换截图，没有编辑保护。WPS 只读渲染前后源文件 SHA-256 一致：`2e45c021811c9cf248ce77ce631a9590010a473dcf0ad5aaeb6ed51108a3fd27`。
- 现有 Windows EXE 与 Android APK 校验值与 0.5.11 发行清单一致；仅整理运行入口，未重建或替换安装包。

- 作品材料中的功能演示为现场操作脚本，没有宣称附带已录制视频。
