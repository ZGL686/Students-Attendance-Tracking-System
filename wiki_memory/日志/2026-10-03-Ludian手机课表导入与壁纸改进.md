# 2026-10-03｜Ludian 手机课表、导入与壁纸改进

- 目标：按用户提供的改进说明优化手机课表、课程导入、考勤记录显示，并增加自定义壁纸与玻璃透明度。
- 来源：用户明确提供已上传至 GitHub 的 `ZGL686/Students-Attendance-Tracking-System` 源码，要求按本地改进说明实施并使用该仓库。
- 索引：[[日志/MOC_工作日志|工作日志 MOC]]。

## 已确认需求与实现

- 手机启动课表时默认显示整周，七天在窄屏内同时呈现；精简课时卡片以保持可读和可点击。
- 课程文件识别成功后自动追加可确认课程并跳过完全重复项；缺字段、周次异常或时间冲突的条目留在修正页；替换课表仍需二次确认。
- 手机考勤历史使用直接可读的窄屏表格呈现课程 / 类型、同学 / 学号和登记时间；调整页面底部与安全区域留白，避免底部导航覆盖内容。
- 外观设置支持从设备选取壁纸，压缩后保存到设备偏好；玻璃透明度可调，最高 30%；壁纸不进入班级数据、考勤记录和完整备份。

## 文件与范围

- 交互：`src/Timetable.tsx`、`src/features/timetable-import/ImportCourses.tsx`、`src/features/attendance/RecordHistory.tsx`。
- 外观偏好：`src/preferences/`、`src/styles/wallpaper.css`、`src/styles/mobile*.css` 与 `src/styles.css`。
- 用户文档：`README.md`、`docs/使用说明.md`。
- 未更改考勤数据结构、课程持久化 schema、Android 签名或发行版本号；未构建 APK / Windows 安装包。
