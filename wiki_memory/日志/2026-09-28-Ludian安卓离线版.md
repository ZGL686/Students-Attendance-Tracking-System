# 2026-09-28｜Ludian 安卓离线版

- 时间：2026-09-28（北京时间）
- 类型：`feature`
- 状态：代码实现完成；原生 APK 等待 Android 工具链与签名环境
- 目标：为 Ludian 增加 Android 手机离线运行、考勤与可审查的手动迁移流程。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 按用户确认的方案，首版是 Tauri Android APK，最低 Android 7.0，复用 SQLite 和业务 schema 3，18 套主题离线内置；无登录、云端数据库或云同步。
- 手机提供课表查看、学生查询、考勤登记与撤销、历史记录、手动 JSON 备份；名单及课程继续在 Windows 编辑，不纳入首版 OCR、PDF 导入或微信小程序。
- 初次导入保留 Windows ID；Windows→手机更新 Windows 名单和课程并保留手机考勤；手机→Windows 按工作台和记录 ID 合并，冲突默认保留 Windows，可逐条选择；缺失记录不触发删除。
- JSON 备份暂未加密，按用户计划仅经本人控制的本地方式迁移。

## 检查与操作

- 增加 Android 平台配置、手机导航和窄屏样式、系统返回处理、Android 文件选择器及 Tauri 单实例插件平台条件。
- 增加首次初始化、Windows→手机更新、手机→Windows 考勤合并和逐条冲突预览；继续通过已有 SQLite 单次保存路径提交。
- Android 前端构建排除 OCR/PDF 运行包；18 张主题图转换为 WebP，保留 PNG 源文件，降低主题资源体积。
- 新增构建、签名与迁移说明；实际 APK 签名密钥未生成或保存。
