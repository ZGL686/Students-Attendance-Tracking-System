# Ludian 0.5.7 安卓批量识别安装包发布

## 目标与结果

- 用户要求将最新识别改进打包为 Android APK，并更新 Git 远程仓库。
- 生成并交付 0.5.7 / versionCode 5007 通用 release APK，支持 ARM64 与 ARMv7，最低 API 24 / Android 7.0，目标 API 36。
- 包内包含多图与文件并集、目录联用、课程格识别提速、阶段连续进度、45 秒任务上限与取消修复。源码基准为 `bd4b99238b43397f99dab0a02d80bf57c1fb3f85`，基于 `eb95829` 识别修复。
- 保持应用标识 `cn.guilu.attendance` 与业务 schema 3，复用当前发布签名；没有生成新的 Windows EXE / ZIP，该发行仍为 0.5.6。

## 构建与文件变更

- `package.json`、根 npm lock 版本、Tauri 配置、Cargo 包及 lock 中本应用版本同步至 0.5.7；没有升级依赖。
- 复用已有 JDK 17、SDK / Build Tools 36、NDK 29 和 Gradle 缓存。当前仓库本地默认工具链路径不存在，构建时显式使用实际安装路径；没有复制或暴露签名口令。
- `npm run android:build` 退出 0，生成单个 universal release APK。生成工程的 Android 原生文件选择器支持 `MODE_OPEN_MULTIPLE` 和全部 `clipData` URI，前端多选入口包含于本包；该项为源码检查。
- 本地 `dist/` 更新 `Ludian-Android-universal.apk`，并提供版本明确的 `Ludian-Android-0.5.7-universal.apk`；更新 `android-version.json` 和 Android 安装说明。两份 APK 完全相同，原 0.5.6 APK 和元数据在本机忽略目录保留。
- README 与使用说明更新版本、并集导入、连续进度及覆盖安装说明；核验与发行记录随 `main` 提交，APK、工具链、密钥和私人诊断不提交 Git。

## 安装与下一步

- 当前同签名 0.5.6 可直接覆盖安装，不先卸载；更新前将完整 JSON 备份保存到应用外。更早的旧签名版本继续按既有迁移说明处理。
