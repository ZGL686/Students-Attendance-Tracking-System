# Ludian 模拟器取消示例学生

## 目标与已确认需求

- 用户依据手机模拟器要求取消默认示例同学展示。
- 新预览的学生名单为空，可继续手动添加或导入名单，保留课表预览。

## 实现

- `src/simulator/demo.ts` 不再生成默认三名学生；保留原示例课程。
- 预览启动时按原始学生的 ID、学号和姓名三项精确匹配，清理这些身份及关联考勤、自定义单元格；保留手动添加及已更名 / 改学号身份和其他工作台内容。
- `AppProvider` 接受可选迁移函数，只有预览入口传入。通过已有乐观版本检查与事务追加新快照，旧快照原样保留；无变化不保存，避免刷新重复迁移。
- 同步模拟器说明、README；已确认的空名单要求记录到当前约束，原封存日志不改写。

## 验证

- `npm run check` 通过：ESLint、92 个模块架构边界、Prettier、TypeScript。
- `npm test` 通过：10 个测试文件、95 项测试。新增 4 项纯数据测试覆盖空名单、所有工作台、关联考勤及属性、输入不变、精确匹配与幂等。
- `npm run build` 通过；原有依赖注释和字体路径提示不阻止构建。
- 23 项端到端检查通过：13 项手机模拟器、3 项手机工作流、7 项应用外壳回归。新增空名单、旧示例清理、手动名单保留、旧快照字节不变及重载不重复保存检查。
- 当前浏览器学生页面无默认示例同学；已有导入名单保留。自动化使用独立浏览器上下文及虚构资料，未测试真实名单或原生 SQLite 数据。
- 新预览空名单截图位于忽略目录 `.local/phone-simulator/empty-students.png`，不提交 Git。

## 结果与待确认长期记忆

- 手机模拟器的学生名单初始为空；默认示例同学不会因刷新重新生成。
- 原始示例身份的关联数据从当前预览版本移除，仍可在旧快照中恢复；此清理只作用于模拟器独立库。
- 本轮为预览行为修正，未重新生成 Windows EXE 或 Android APK。
- 无新增待确认长期选型；旧模拟器参数及实体手机验收边界仍以原日志为准。
