- 在独立工作树安装锁定依赖，运行 `npm run release`，构建 Windows EXE、解压目录和 ZIP。

- 将已核验的 EXE/ZIP/APK 及 `android-version.json` 更新到 `D:/GitSoftware/-/dist/`。
