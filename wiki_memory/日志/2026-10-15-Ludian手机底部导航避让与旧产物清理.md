# Ludian 手机底部导航避让与旧产物清理

## 用户需求与边界

- 手机底部五项导航的图标和文字整体上移，避开系统三按钮或手势区域，保持文字可读、点击方便及操作简洁。
- 清理明确的旧版本发行副本和无用测试产物；保留最新 Windows EXE / ZIP、最新 Android APK、已核对的 Excel 课表、个人课表 / 名单 / 考勤 / 备份、签名、工具链和依赖。
- 版本目标为 0.5.10，手机 Excel / CSV 导入及桌面图片 / PDF 的范围保持；不更改业务 schema、应用标识或已有数据。

## 导航与说明

- 底部导航的图标、文字和操作区域需整体位于系统导航区域上方，页面内容与导航同步留出空间；原生 Insets 和浏览器模拟安全区分别验证。
- 保留课表、考勤、学生、记录、备份五项入口，避免增加复杂设置步骤。课程导入保持“选择文件 → 自动追加保存”，错误时直接说明原因。
- README、使用说明及 Android 构建说明更新为 0.5.10，并明确旧包清理边界。
- 网页导航改用独立明暗实体底色与高对比文字，按钮至少 52px 并随字体增高，移除重复字号规则。原生已缩小 WebView 时只保留 6px 内部间距；模拟器继续使用三键 / 手势安全区，避免双重留白。
- 原生 `MainActivity` 在 `super.onCreate` 后将 `AppWindowInsets` 安装到稳定的 `android.R.id.content` 父容器。系统栏、屏幕缺口和键盘的四边 Insets 取每边最大值，不叠加键盘与导航栏；已处理的 Insets 归零后继续向 WebView 分发，避免重复或残留留白，没有新增 JavaScript 桥接。
- `prepare-android-native` 自动同步 MainActivity、Insets 实现及原生测试模板；已有不同生成副本先本地备份。原理和避免重复留白的边界同步到 `src-tauri/android/README.md`，参考 [Android 官方 WebView Insets 说明](https://developer.android.com/develop/ui/views/layout/webapps/understand-window-insets)。

## 盘点与实际清理

- 只盘点当前仓库 `dist`、`.local`、测试报告、Rust 目标及生成 Android 构建目录，没有访问默认用户数据目录或读取签名内容。
- 本机 `.local/nav-0510-cleanup-candidates.json` 记录 12 个精确候选，写入时合计 1,058,223,640 字节。范围为旧 0.5.7 / 0.5.8 / 0.5.9 版本化 APK、旧 APK 核验副本、旧 Playwright 输出，以及 0.5.9 的已核验内置前端副本。
- 新版 APK 发布核验通过后，按固定白名单逐项检查最终绝对路径、父目录与子项，拒绝越界、链接、数据库、表格和签名文件；与盘点字节数一致后才删除。已清理全部 12 项，释放 1,058,223,640 字节，结果记录在本地忽略目录，旧 Android 0.5.7 / 0.5.8 / 0.5.9 版本化安装包均不存在。
- 新测试使用本轮独立输出目录，不写入被清理的旧测试目录；保留新验证证据。已核对 Excel、Windows 最新 EXE 和 ZIP 清理前后哈希一致，业务数据和备份未访问或清理。
- OCR 诊断中的原图比对结果可能仍用于验证，未加入整目录删除；真实课表生成资料、已核对 Excel 和本地模拟器截图继续保留。Rust `target`、Android 工具链和签名不在本轮候选内。
- `D:/dist` 与 `playwright-report` 在盘点时不存在。Git 历史、工程记忆与源文件不作为清理目标。

## 最终验证与发布

- `npm run check`、完整 310 项单元测试通过。原生模板准备 13 项测试包含在其中；真实 Kotlin / AndroidX 编译运行的 Insets JUnit 4 项通过，覆盖三键、手势、横屏两侧、键盘取最大值与隐藏恢复、基础 padding 不累计。
- 相关端到端共 32 项通过：导航和手机模拟器 18 项，加课程导入与手机备份回归 14 项。覆盖五页切换、52px 点击区域、明暗文字对比度至少 4.5、320px 窄屏、200% 字号、横屏、系统区域与页面末端边界、导入重复 / 取消 / 保存失败、备份恢复。模拟器截图已检查，文字和图标完整位于系统按钮上方。
- Android 与普通网页生产构建均通过。Android 生产前端应用 Android CSP、禁用 Worker 并阻断外网时，个人已核对 Excel 的 11 个安排 / 9 个名称逐字段一致，一次保存、重新打开保留、重复不写入，虚构学生和历史考勤保留。
- 双架构 release APK 版本 0.5.10 / 5010，包名 `cn.guilu.attendance`，最低 SDK 24、目标 SDK 36。大小 97,558,388 字节，SHA-256 `2df1507840bfaa13fd2c695223ee04b6bae40bd7762c443965fa1fec006ddbae`。版本化 APK 和 latest 下载入口一致，更新安装说明和版本 JSON。
- APK V2 签名通过，证书 SHA-256 `79ca1a91c812011a323d5f2fcddd7ab464bf24f66d0f4da7d1b6a65fd1fe3335`，与 0.5.3–0.5.9 一致。16 KB ZIP 对齐通过；ARM64 LOAD 为 16 KB、ARMv7 为 4 KB。
- 每 ABI 匹配当前 35 份非 HTML 资源与 1 份 HTML 的实际嵌入内容，无 OCR / PDF / WASM 资源和旧 Worker 类。结合 fresh R8 映射及实际 DEX 验证 `AppWindowInsets`、请求重新派发的回调，以及内联到 MainActivity / 回调中的 padding 和 Insets 归零代码，确认修复进入 APK。
