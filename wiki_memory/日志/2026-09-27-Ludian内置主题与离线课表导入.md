# 2026-09-27｜Ludian 内置主题与离线课表导入

- 类型：feature。
- 状态：0.5.0 实现、全量自动回归和隔离原生 Debug 功能验收完成；截至本记录，正式发布与最终发行哈希待补充。
- 目标：增加完整视觉主题和本地课表文件导入，保留旧数据、历史考勤与设备偏好。
- 日志索引：[[日志/MOC_工作日志]]。

## 用户明确范围

用户在本轮取消登录和云端数据库 / 云主题方案，要求主题全部内置且增加数量；本版范围为 18 套完整视觉主题及经典外观。用户要求的宫崎骏风、二次元、国漫继续覆盖，并扩展自然、城市和幻想风格。应用保持本地运行，不提供账号、云目录或下载刷新入口。

用户批准本地课表导入方案，支持图片、Excel / CSV 和 PDF，识别后预览核对、纠错再保存。主题选择、字体与明暗偏好保持独立；现有名单、工作台、课表、历史考勤和备份兼容继续作为约束。上述明确需求已写入 [[当前状态/项目概览]]、[[当前状态/当前约束]] 和根 AGENTS.md；具体代码选型仍为 proposed。

## 实现与文件

- `src/features/themes/`：纯本地受控 schema、18 套浅深配色与装饰、分类图库、预览和手动应用；`public/themes/` 提供全部图片。原六个 ID 保留，无任意 CSS / HTML / 脚本主题入口。
- `src/preferences/`：设备偏好改为 v2；仅在当前键不存在时读取 v1，完整保留原明暗、字体、字号、动效和侧栏字段。经典为新增视觉主题默认值；保留的旧键不覆盖已有 v2，未知主题可回退。
- `src/styles/theme-packs.css`：主题背景、侧栏、标题、面板、按钮与受控装饰；课表和考勤表格实色显示，保留业务语义颜色。
- `src/features/timetable-import/`：文件与来源选择、Excel / CSV 解析、PDF 文字和扫描页读取、中文 / 英文 OCR、草稿编辑校验与事务提交。
- `scripts/prepare-offline.mjs`、`public/offline/`：从固定版本依赖准备 OCR / PDF Worker、WASM、语言包、字体、许可与文件哈希清单；生成资源随构建打包，不依赖运行时 CDN。
- `docs/使用说明.md`、`docs/架构与交互规范.md`、`docs/验收记录-0.5.0.md`：功能步骤、边界、离线构建和已通过验证；正式发布状态单独记录。

导入草稿不写入业务数据；缺少名称、星期、节次或周次时留空，教师与教室可为空。周次支持不连续段及单双周；连续节次可以归并，不连续节次与证据不足的网格定位不猜测。默认追加、完整重复跳过、重叠冲突阻止继续，替换必须再次确认。

提交重新验证原目标工作台、使用状态、当前工作台、课表 / 学期指纹和乐观版本，通过原事务保存成功后才关闭窗口。取消或识别失败不改课表，保存失败保留当前草稿。替换仅更新课程列表，历史考勤的课程、教师与教室快照不变；原文件和 OCR 草稿不进入备份。业务 schema 保持 3，原应用与存储身份不变。
