# 2026-09-30｜Ludian 手机完整交互改造

- 目标：按用户后续要求重新排版手机界面，符合手机屏幕与操作习惯，并尽可能保留桌面功能。
- 来源：用户明确否定首版体验，要求恢复完整交互；后续授权继续配置工具并交付可安装 APK。
- 索引：[[日志/MOC_工作日志|工作日志 MOC]]。

## 已确认需求与实现

- 后续需求取代手机仅查看、禁止编辑的首版范围；保持离线、无登录和无云端。
- 增加每日课表、星期切换、完整周课表横向滚动；恢复课程新增、编辑与图片 / Excel / CSV / PDF 本地导入。
- 手机学生和记录页提供便捷列表及完整数据库，保留桌面属性、视图、筛选、排序和批量操作；恢复学生新增、考勤明细编辑、批量登记、撤销与恢复。
- 底部五项短导航，顶栏统一工作台入口和全部功能菜单；汇总、设置、新建及管理工作台可达。
- 适配触控目标、窄屏弹窗、抽屉、表单、安全区域及系统返回对抽屉的处理。手机首次空工作台命名为“我的工作台”。
- APK 内置 OCR/PDF Worker、WASM 和语言包；18 套主题保持离线 WebP。版本升至 0.5.1，复用 0.5.0 签名及包名；业务 schema 3 与持久化协议未改变。
- 手动合并仍以 Windows 学生 / 课程为准，仅合并手机考勤。手机独有资料通过完整备份恢复为副本；说明书明确此边界。

## 工具链与文件

- 已补全 JDK、SDK / NDK、两种 Rust Android target、Gradle、签名及开发者模式；私密密钥和生成工程均在 Git 忽略范围。
- UI：`src/app/`、`src/features/database/`、`src/features/timetable/MobileAgenda.tsx`、`src/styles/mobile*.css`。
- 业务入口：`src/App.tsx`、`src/Timetable.tsx`、`src/Attendance.tsx`、学生 / 记录 / 备份模块。
- 构建：`scripts/build-android.mjs`、`vite.config.ts`、各版本文件；移除 Android 空导入组件。
- 测试：`tests/e2e/mobile-workflows.spec.ts` 和 `mobile-parity.spec.ts`，全部使用虚构资料。

## 验证与结果

- 代码质量、90 项单元测试已通过；完整端到端回归及最终 APK 核验结果以 `docs/0.5.1-安卓验收记录.md` 为准。
- 手机浏览器测试涵盖 360 / 393 / 430 像素、Android UA、横屏、导入编辑、主题、持久化、批量考勤和导出；真实 APK 内的原生行为须另验。
- 先前构建已成功产出 ARM64 / ARMv7 0.5.1 APK；修复旧 CSS 隐藏批量 / 明细编辑入口后重新打包。
- 未连接实体手机；本机未报告可用的虚拟化加速。原生冷启动、系统文件选择器、键盘、返回键和覆盖更新未声称通过。
- 本轮不重新发布 Windows EXE / ZIP；已有 Windows 发行文件不等同于 0.5.1 安卓包。

## 遗留与待确认长期记忆

- 用户需实机体验排版；真实设备安装及覆盖更新验收仍待执行。
- 功能扩大为手机可编辑来自明确用户需求，更新当前约束；具体每日 / 完整视图布局仍为待验收实现。
- 签名密钥应由用户在受控独立位置备份，不随 APK 或源码分发。
