# Ludian 移动应用竞赛答辩 PPT 交付

## 任务与内容

- 按用户提供的“2026 年第十四届全国大学生数字媒体科技作品及创意竞赛”“移动应用赛道”制作 15 页、16:9 可编辑 PPTX，作品名称为 Ludian 考勤系统。
- 叙事覆盖需求、目标用户、整体方案、三页实际功能、业务闭环、技术架构、三项特色、测试、安全、应用价值及总结。正文使用短句，配色为浅底、科技蓝与深蓝文字。
- 两名目标使用者按课堂登记、复核归档说明典型任务侧重，未推断其职务，也未虚构账号权限角色。三项特色为课程快照、整批自动导入、离线事务及修订号保护。
- 各页备注保留可直接讲述的讲稿及资料依据，建议总时长 460 秒，即约 7 分 40 秒，不代表已做现场计时演练。
- 手机图片来自当前 0.5.12 源码的隔离 Edge 手机布局，440×960、DPR 2，预置虚构资料并阻断个人种子与外网。页面可见标注浏览器演示，未将其写成实体 APK 截图。另使用此前隔离运行的 Windows 0.5.12 实际界面。

## 真实性边界

- 手机功能仅介绍 Excel / CSV 导入，未宣传已取消的手机 OCR / PDF、人脸、定位签到或云同步。
- 测试表明确区分 0.5.11 的历史 377 项单元、36 项相关端到端、4 项原生 Insets 测试，以及 0.5.12 的质量、28 个浏览器页面状态、构建与包体核验。
- Android 实体设备覆盖安装、重启保存、性能和机型记录使用“待补充实际测试结果”，未编造用户数量、准确率、响应时间、部署数量或效率提升比例。
- 安全页区分已实现的本地目录、事务、修订号、摘要及结构校验，以及无账号分级、JSON 未加密等当前边界。备份加密与访问保护仅作为待评估建议，不作已实现或合规认证声明。

## 检查与交付

- 使用 Artifact Tool 生成原生 PPTX。文字、流程图、架构图及测试表格可编辑；界面截图保留为独立图片。
- 最终文件包含 15 页与 15 页讲稿备注、1 个原生表格、12 条原生连接线。结构、尺寸、标题适配、字体与原生表格检查通过，阻断项和样式警告均为 0。
- 最终文件重新导入并渲染 15 页，逐页目检；最后仅修改讲稿后再次渲染，15 页画面哈希与已目检版本一致。修正了流程箭头方向、截图字段裁切及来源文件路径。
- 使用微软雅黑，主标题与正文保持投影可读的字号。当前环境未注册 WPS 演示 / PowerPoint COM，因此未宣称在其原生程序打开验收。
- `npm run check` 通过 ESLint、114 模块边界与循环检查、Prettier 和 TypeScript。本轮未修改应用源码、未新增或运行应用测试套件。
- 最终文件：`dist/Ludian竞赛答辩/Ludian考勤系统_移动应用答辩_可编辑.pptx`，1,388,387 字节，SHA-256 为 `402301f8e11586f870f970b69c314b2b6058ddfcd40a99bef5d8794757e9465c`。
- 交付目录仅保留定稿。源脚本、资料审计、截图与验证报告位于忽略目录 `.local/competition-ppt-20261020/`；个人 PPT、截图和数据不提交 Git。本轮仅提交工程日志与索引。
