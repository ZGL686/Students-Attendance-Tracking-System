# Ludian 架构与交互规范

适用于 0.5.0。本文描述当前代码中的工程约定，长期实现选型仍按工程记忆协议保持 proposed，等待用户验收。用户已明确本版取消登录和云端服务，主题全部内置，课表文件在本机处理。

## 职责边界

- **应用外壳**：`src/app/` 管理导航元信息、顶栏、侧栏和班级切换。页面标题与导航共用同一份定义；更名只影响产品展示，不能顺手更换存储标识。
- **公共 UI**：`src/components/ui/` 提供 Button、IconButton、TooltipProvider、Popover、Modal、Drawer、Toast、PageHeading 和 ErrorBoundary。公共组件不导入业务上下文、数据库或特性模块；业务通过属性传递内容与回调。
- **特性模块**：数据库分为页面协调、查询模型、操作、表格 / 卡片 / 布局、属性编辑和配置；学期设置、备份、名单导入分离；考勤完整编辑器独立，登记页面与数据库共用。
- **业务与保存**：数据库查询、校验与考勤逻辑保持在独立纯逻辑模块。所有业务修改继续通过原 `change / update`、版本冲突检查和事务保存，成功后才更新界面；失败状态在顶栏保留到下一次成功或重新读取。
- **设备偏好**：明暗模式、视觉主题、字体、字号、动效、侧栏状态在独立 PreferencesProvider 中管理，经结构校验后保存到 `ludian.preferences.v2`。仅当前键不存在时迁移 v1，保留原明暗、字体、字号、动效与侧栏字段，新增视觉主题默认为经典；旧键保留，但不会覆盖已有 v2。错误字段回退默认值，读取失败不阻断应用；写入失败提示仅当前会话有效。偏好不混入考勤数据或备份。
- **内置主题**：`src/features/themes/` 维护受控数据 schema、18 套配色与装饰、预览和应用，图片位于 `public/themes/`。只使用已打包的定义与图片，不提供账户、云目录、下载或远程刷新入口。
- **课表导入**：`src/features/timetable-import/` 分离文件读取、Excel 网格、文本位置解析、OCR、草稿校验、导入窗口与提交检查；预览草稿不写入业务数据。导入和手工课程共用 `courseSchema`，最终通过已有事务保存路径写入。

## 布局与交互

- 外壳使用明确的 `sidebar / main` 网格区域；主区域永远放在 main，不依赖隐藏侧栏后的自动排列。折叠仅调整列宽与侧栏可访问性；展开按钮始终在顶栏。
- 班级名称是唯一工作台切换入口，支持当前选择、新建、外部点击和 Escape 关闭。取消重复品牌标题与工作台列表。
- 图标按钮必须提供语义标签，通过 IconButton 获得统一提示。公共浮层在视口范围定位；提示在原生 dialog 内使用其顶层容器，避免被遮住。
- Modal 使用原生 dialog 的焦点约束、标题关联和 Escape；点击内容区留白不视为点了背景。Drawer 是非模态侧面详情，保留背后数据操作；关闭后在合适情况下还原焦点。
- 背景 / 边框反馈约 120ms，弹窗约 180ms，抽屉约 220ms。图标只做小位移 / 按下缩小；不使用持续装饰动画、全局 `transition: all` 或文字 transform 缩放。
- 组件的加载状态通过公共 Button 的 pending、顶栏保存状态和通知说明结果。看板拖动显示落点和源卡片状态，列拖动显示插入位置。
- 系统减少动态效果或应用手动减少动效时关闭动画和过渡，保留焦点、高亮和状态文案。

## 样式和字体

样式入口只负责按顺序导入。设计变量、字体、基础控件、外壳、各功能页面、浮层、响应式和交互分别维护；公共改动优先修改变量 / 公共规则，避免逐页覆盖补丁。

字号使用 rem 与根字号联动；提供 14 / 15 / 16 三档，保留默认宽度和控件最小高度，不用 zoom 或拉伸文本。默认圆体；手写、原黑体及系统字体可即时切换。第三方字体固定版本、完整保留版权和许可证，记录文件哈希。

主题库按治愈动画、二次元、国漫、自然、城市、幻想分类，另保留经典外观。每套主题提供浅深配色、背景图、面板圆角和受控装饰；禁止把任意 CSS、HTML 或脚本作为主题定义。预览可独立切换明暗，只有点击“应用主题”才改变视觉主题，不修改明暗模式、字体、字号和动效。分类与卡片支持键盘选择，弹窗取消或 Escape 保持原选择；旧偏好引用本版不存在的主题时使用经典外观并提示重新选择。

主题变量覆盖表面、边框、侧栏和操作按钮，考勤类型与课程语义颜色继续由原样式控制。背景图放在页面留白与标题区域，课表 `.calendar`、考勤表格和编辑面板使用实色表面，避免背景透过内容。正文、次要文字、表格灰字、侧栏文字与主按钮文字分别在全部 18 套明暗配色中检查至少 4.5:1 对比度；新增主题需要延续这项检查。

## 本地课表导入

入口为课程表中的“导入课程”。支持 PNG、JPEG、WebP、BMP、`.xlsx`、UTF-8 CSV 和 PDF；`.xls` 与加密 PDF 给出转换提示。单文件上限 20 MB、PDF 上限 50 页、图片上限 2400 万像素。Excel 工作表与 PDF 页面允许选择，默认选第一项。

Excel / CSV 优先读取结构化列，兼容星期 × 节次网格。合并单元格仅在节次连续且星期明确时合并；`第1、2节`可归并为 1–2，`第1、3节`不能补成 1–3。OCR / PDF 文本按实际位置建立有限的表头区域，不把距离很远或证据不足的课程归入最近节次。周次保留范围、不连续段和单双周；缺少名称、星期、节次或周次时留空供人工填写，不默认整学期。教师和教室可为空。

图片使用本地中文 / 英文 OCR，PDF 优先读文字层，文字不足或不可用时渲染所选页再做 OCR。识别结果保留来源、原文与提示，允许增删、改写、排除课程，支持失败后手工录入。进度与取消通过统一读取选项传递，取消时终止识别、销毁 PDF 任务并释放画布；取消和识别失败不修改现有课表。

默认追加，完全重复课程跳过。相同星期、节次与周次交叉的冲突必须修正或排除；课程周次不得超过当前学期总周数。替换模式需要第二步明确确认，并显示原有课程数量。导入绑定开始时的工作台，提交时重新校验目标仍存在且使用中、当前工作台未切换、课表与学期指纹未变化，并在原乐观版本检查和事务边界内再次校验草稿。保存失败保留草稿；只有持久化成功才关闭窗口并显示成功。

替换仅更新目标工作台的课程列表，不删除学生，也不重写历史考勤中的课程、教师和教室快照。原文件、OCR 画布及草稿不进入考勤备份。业务 schema 继续使用 3，应用标识、SQLite / IndexedDB 身份和备份格式不因本轮特性改变。

## 离线资源与依赖

`scripts/prepare-offline.mjs` 在开发及生产构建前，从安装好的固定版本依赖生成 `public/offline/`，包括 OCR Worker、WASM、简体中文 / 英文语言包及 PDF Worker、字体和 CMap 等资源，同时输出版本、文件大小与 SHA-256 清单及许可。生成资源不提交 Git，构建产物必须完整打包；使用过程不从 CDN 下载，也不上传课表。

当前依赖为 Tesseract.js / Core 7.0.0、PDF.js 6.3.289、中文 / 英文语言数据包 1.0.0。资源版本与包版本不匹配时准备脚本失败。Tauri CSP 保留同源 Worker 和 WASM 执行所需权限，连接范围为本地 IPC、同源与本地 Blob，不加入远程主题源。离线验收必须使用全新 WebView 配置，验证首次中文 OCR 可运行且没有外部请求，不能仅依赖已有浏览器缓存。

## 质量检查与发布

执行 `npm run check`：ESLint 检查 Hooks、类型导入、重复导入、显式 any 等；架构脚本检查相对模块依赖环、UI / 业务边界，以及单文件规模；Prettier 只读校验与 TypeScript 严格检查。体积阈值是避免模块不断膨胀的护栏，不能替代代码审查。

执行 `npm test`、`npm run test:e2e`、`npm run build`；Rust 改动另运行 Cargo 测试。公共控件或保存路径改动需执行隔离桌面验收，使用虚构学生。SQLite 通过 `GUILU_DATA_DIR` 隔离，WebView2 通过 `WEBVIEW2_USER_DATA_FOLDER` 隔离；操作前检查 Tauri 返回的数据目录和实际 WebView 子进程路径。不能在 Tauri JSON 中使用绝对 `dataDirectory`，该配置会被忽略。回归必须实际检查内容区宽度、可见控件和往返操作，不能只断言没有 JavaScript 报错。

最终使用 `npm run release`，交付 `dist/Ludian-latest/Ludian.exe` 和同名 ZIP。核对文件一致、图标 / 产品名称、原目录兼容、发行版无调试端口后更新验收与记忆，提交推送。旧发行物仅归档到本机忽略目录，学生名单、数据库与个人包不进入 Git。

## 延续的工作台与考勤约定

- 工作台生命周期的纯逻辑放在 `features/workspaces/model.ts`。移入回收站只标记 `deletedAt`，不删除学生 / 课程 / 考勤 / 自定义属性；切换菜单只展示使用中的工作台。删除当前项与选择替代工作台在同一事务完成；模型与界面均保护最后一个工作台。
- Schema 3 兼容读取 1 / 2，保留原快照。旧版拒绝读取 3，避免静默丢弃回收站标记。备份包含回收站，导入副本保留删除状态并选中使用中的副本。
- 主题采用语义变量，基础与特性样式共用 `tokens.css`，不通过反色滤镜实现。跟随系统监听媒体变化，手动主题独立保存；Tauri 标题栏同步主题。固定明暗缩略图是展示样本，可使用固定颜色。
- ChoiceCards 统一字体 / 主题的单选语义和方向键行为；TopLayerPortal 把全局通知放在最上层原生弹窗内，确保保存失败可见、可关闭。
- 考勤减号打开按学生和类型筛选的记录列表，优先展示当前日期 / 课程，撤销具体记录。`features/attendance/model.ts` 的 `setRecordsVoided` 为登记页、详情及数据库共用；仅修改状态与更新时间，保留课程快照和自定义属性。最近登记条支持批量撤销与恢复；历史更正通过持久化记录完成。

0.5.0 的自动检查、隔离原生验证与正式发布状态分别记录在 [验收记录](验收记录-0.5.0.md)，不得把 Debug 功能验证等同于最终发行 EXE 验收。
