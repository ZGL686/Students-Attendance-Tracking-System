# 项目目录与清理说明

## 打开项目

| 用途           | 入口                                                                              |
| -------------- | --------------------------------------------------------------------------------- |
| Windows 成品   | `dist/Ludian-latest/Ludian.exe`                                                   |
| Windows 压缩包 | `dist/Ludian-latest.zip`                                                          |
| Android 安装包 | `dist/Ludian-Android-universal.apk`                                               |
| 手机模拟器     | 根目录 `启动手机模拟器.cmd`，再访问 `http://127.0.0.1:15473/phone-simulator.html` |
| 网页开发       | 根目录执行 `npm run dev`，访问 `http://127.0.0.1:15473/`                          |

开发需先安装 Node.js，首次克隆后执行 `npm ci`。本机已有依赖时直接启动即可。Windows 成品需要 WebView2；日常数据目录与安装包分开，详见 [使用说明](使用说明.md)。

## 文件归属

| 目录 / 文件                  | 内容与处理方式                                                    |
| ---------------------------- | ----------------------------------------------------------------- |
| `src/`、`src-tauri/src/`     | 前端、原生源码；保持 GitHub 中的结构                              |
| `public/`                    | 图标、字体、主题；`offline/` 是桌面离线导入资源，不是无用缓存     |
| `scripts/`、`tests/`         | 构建、检查和测试；保留源码                                        |
| `docs/`、`wiki_memory/`      | 使用说明、设计依据、工程记录；保留历史                            |
| 根目录配置、锁文件、启动入口 | 保证开发与构建可复现；保留                                        |
| `dist/`                      | 最新 Windows / Android 成品、说明及本地参赛资料；不提交 Git       |
| `downloads/`                 | 已核验的公开 APK / EXE、校验值和版本清单；与 GitHub Release 同步  |
| `.local/`                    | 私人资料、签名、诊断、材料源码与素材；按用途保留，不整体清空      |
| `node_modules/`              | 已安装的开发依赖；保留以便直接打开项目                            |
| `web-dist/`                  | 网页构建输出，Tauri 打包读取；由 `npm run build` 更新             |
| `src-tauri/target/`          | Rust 编译输出与依赖缓存；可清明确中间缓存，保留当前运行和打包入口 |
| `src-tauri/gen/android/`     | Android 生成工程；其中签名配置、Gradle 配置与当前构建入口仍有用途 |

## 本地清理原则

- 先 `git fetch origin --prune` 核对远程及本地改动；不因文件未受 Git 跟踪就认定无用。
- 优先删除编译临时文件、旧序列化中间物、无引用且哈希相同的副本。
- 保留最新 ZIP 和对应解压目录；Android 稳定名称与带版本名称可作为同一版本的交付入口。
- 保留数据库、完整备份、名单、原图、已核对课表、签名和工具链。素材路径被生成脚本引用时保留位置。
- 删除前核验绝对路径、Git 跟踪情况和目录链接；仅在项目目录内操作，跳过 junction / reparse 链接。
- 清理后检查源码、成品哈希、质量检查、网页构建和实际启动；具体结果记入工程日志。

`dist/` 与 `.local/` 属于本机资料，不在远程仓库中；重新克隆 GitHub 仓库不会自动恢复其中的文件。
