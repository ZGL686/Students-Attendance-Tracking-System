# Ludian 0.5.4 使用说明

发行包的版本、构建时间与 `Ludian.exe` 的 SHA-256 记录在同目录的 `version.json`，可用于核对文件完整性。

## 打开应用

双击同目录下的 `Ludian.exe`。应用在本机离线运行，不需要注册账户。Windows 10/11 需具备 Microsoft Edge WebView2 Runtime。

个人版首次启动载入提供的班级名单和 2026–2027 第一学期课表。之后只读取已保存数据，更换程序不会重新初始化。源码通用版不带真实名单，可以新建工作台自行导入。

## 第一次使用

1. 在“学期设置”核对开学日期。初始为参考截图中的 **2026 年 9 月 7 日**，可随时修改，所在周的周一为第 1 周起点。
2. 核对学校作息，尤其是第 9–10 节。没有明确时间的实践课程暂列于学期备忘。
3. 在“课程表”点击课程查看详情，可编辑周次、教室、教师、时间节次，或直接为该课程记考勤。

## 导入课程表

在需要接收课表的工作台中，点击“课程表 → 导入课程”。导入窗口会显示目标工作台名称。

1. **选择图片或文件**：可从相册上传课表图片，或选择 Excel `.xlsx`、UTF-8 `.csv`、PDF。单个文件最大 20 MB；PDF 最多 50 页。旧 `.xls` 请另存为 `.xlsx`。
2. **自动识别并保存**：选择后立即开始处理全部工作表或页面，识别完成自动追加课程，不再进入检查修改或确认保存页面。文件和 OCR 均在本机离线处理。
3. **结果提示**：重复课程自动跳过；信息缺失、周次超出学期或时间冲突的课程不会强行写入，直接显示未导入数量与原因，可上传更清晰完整的课表重试。

Excel / CSV 可使用“课程名称、任课教师、教室、星期、开始节次、结束节次、上课周次”列，也支持星期 × 节次网格。周次支持 `1-16`、`1-8,10-16`、单双周，每天最多 10 节。原图应保留星期、节次和周次信息；教师和教室可以留空。

识别期间可取消，保存期间请等待结果。导入只追加课程，保留已有课表、学生及历史考勤快照；切换工作台后不会将结果写入其他班级。

## 在学生页导入名单

学生页同时提供“添加学生”和“导入学生名单”；手机便捷列表及完整数据库均可直接导入。支持 Excel `.xlsx` 第一张工作表、UTF-8 CSV，最大 10 MB。表头包含“姓名”和“学号”，可选“班级”。

选择文件后自动添加学生。同一学号且姓名相同的学生会跳过；同一学号对应不同姓名时保留原学生并显示冲突。不会清空已有名单、修改学生 ID 或删除考勤记录。文件内部重复学号、缺少必填字段时整份名单不保存，需修正文件后重试。

## 登记考勤

在“考勤工作台”核对登记日期、北京时间和课程。系统进入页面时匹配当前课程，也可点击“匹配当前课程”重新匹配。无课时会要求手动选择课程或填写临时课程名称。

点击某位同学对应类型下的 `+`，增加一条完整记录。不是只修改数字；记录包含日期、时间、课程、教师、教室和备注。重复点击会登记多次，误操作可立即撤销。

- 批量登记：勾选同学，点击“批量登记”，选择考勤类型。
- 补记：点击“补记考勤”，选择同学、日期、课程、类型。
- 个人明细：点击姓名或行末箭头，查看记录，编辑日期、课程或备注。
- 减号：点击类型次数旁的 `−`，展开该同学、该类型的具体记录，按日期和课程选择撤销；所选日期与课程优先展示。次数为学期累计，减号不会盲目删掉其他课程的记录。零次时减号禁用。
- 撤销 / 恢复：最近登记提示条可撤销整次操作（包括批量、补记），也可立即恢复。离开页面或重启后，仍可通过减号或个人明细更正；勾选“显示已撤销记录”可恢复历史记录。

计数是异常考勤登记次数。“—”表示无异常记录，不代表已经确认出勤。

## 新的班级或课程

点击左上角班级名称，再选择“新建工作台”，选择学生名单 `.xlsx` 或 UTF-8 `.csv`。第一张工作表至少包含“姓名”和“学号”表头，可另有“班级”。重复学号、缺失姓名或学号会被提示，修正后再导入。

确认预览后创建，可选复制当前课表。也可以只填名称创建空工作台，之后添加学生或导入名单。不同工作台的考勤和名单互相独立，左上角点击名称切换。

点击“班级名称 → 管理工作台”，可编辑名称与学期标签、切换或删除工作台。删除需确认，会把全部学生、课程、考勤和自定义属性移入回收站；在管理窗口切换“回收站”即可恢复，重启后仍保留。删除当前工作台后会自动切换到另一个工作台。至少保留一个使用中的工作台，需要替换时先新建。

## 学生数据库与考勤记录

这两个页面提供 Notion 式数据库操作。一个数据库可以有多个视图，各视图显示同一批记录；修改一个单元格，会同步到其他视图。

- **表格、看板、画廊、列表、日历**：点击顶部视图标签切换，`+` 新建视图。再次点击当前标签，可重命名、修改布局、复制或删除视图。删除视图不删除记录。
- **筛选与排序**：右上角漏斗设置条件，可选择满足全部条件（AND）或任一条件（OR）；排序支持多条规则，按从上到下的优先级执行。数字按数值排序，空值放在最后。
- **显示列与分组**：视图设置中可隐藏属性、上下调整顺序、换行、按属性分组。表头支持拖动调整顺序，点击表头可排序、隐藏、设置列宽。表格横向滚动时，姓名 / 记录标题固定在左侧。
- **属性**：点击表格右侧 `+`，或右上角“属性与视图设置”，新增文本、数字、单选、多选、日期、复选框。点击单元格修改后保存。已有属性可以重命名；为避免转换损失，暂不直接更改已有属性的类型。已使用的单选 / 多选选项必须先从记录中移除，才能删除选项。
- **批量修改**：勾选多条表格记录，选择“编辑属性”。操作只应用到当前筛选结果中仍被选中的记录。
- **列计算**：表格底部可选择计数、非空、唯一值；数字与汇总属性还可计算合计、平均、最小和最大值。计算范围为当前筛选结果，分组表格各组单独计算。
- **看板**：可将卡片拖到另一列，修改其分组属性。例如把学生从“未设置”拖到“跟进中”。由考勤自动汇总的属性与历史课程快照不能拖动修改。
- **日历**：考勤记录默认按登记日期排列；学生数据库也可新建日期属性，并在日历视图设置中选作日期依据。没有日期的记录显示在日历下方。
- **详情与关联**：点击记录标题或卡片，在右侧打开详情。学生详情列出关联考勤；考勤详情中的同学名称可以跳转回学生。变更考勤所属同学后，双方的异常次数同步重算。
- **导出视图**：工具栏下载按钮导出当前筛选、排序及显示列的 CSV，包含自定义属性。它用于整理数据，不用于恢复工作台。

学生数据库的请假、旷课、迟到、早退和异常累计都是有效考勤记录的自动汇总，不能直接覆盖计数。需要更正时，修改或撤销关联考勤。跟进状态是独立的管理标记，不会改动原始考勤。

每个工作台独立保存属性定义、单元格、视图与当前视图。新工作台不会继承其他工作台的自定义属性值。

## 导出汇总

在“考勤汇总”中选择日期和课程。Excel 包含“考勤汇总”和“考勤明细”两张表；Markdown 同时包含汇总表和明细表。桌面版会弹出保存对话框。

已撤销记录不计入汇总。临时课程和课表里已删除的课程仍保留在已有明细中。需要覆盖全部日期时点击“全部记录”。

## 备份、恢复和更新

“数据与备份”中的完整 JSON 包含所有工作台（含回收站）、学生、课程、考勤、已撤销记录、自定义属性及保存的视图。建议每次重要登记后，导出到另一可靠位置。Excel 汇总不能用于完整恢复。

导入完整 JSON 时先校验内容，显示待恢复工作台，确认后创建“恢复副本”；原工作台继续保留。恢复后从左上角班级菜单选择需要继续使用的工作台。

最近 30 次保存快照可从应用中恢复为副本。所有历史快照保留在本机数据库中；长期使用数据库体积会增长。快照不能代替保存在另一设备上的备份。

更新时：退出应用，保存完整备份，把新版压缩包解压到新目录，再运行新的 `Ludian.exe`。同一 Windows 用户下会自动读取原数据。不要删除应用在“数据存储位置”显示的目录，也不要在运行中单独搬动 SQLite 文件。

### Android 手机与 Windows 手动迁移

Android 版在手机本地保存数据，不需要注册或联网。安装 `Ludian-Android-universal.apk`；更新时直接安装同签名新版，不要先卸载。第一次打开可导入 Windows 完整 JSON，也可从右上角“全部功能”新建班级。空白手机首次导入保留原工作台、学生、课程和考勤 ID。

底部五个入口为课表、考勤、学生、记录和备份；汇总、设置和工作台管理在右上角“全部功能”。课表默认打开整周视图，七天同时排在手机屏幕内；仍可切换每日安排。手机支持添加、编辑和本地导入课程；学生与记录页可切换便捷列表和完整数据库，后者以纵向字段卡片直接显示全部已选属性，无需左右滑动，并保留自定义属性、视图、筛选和批量操作。学生便捷列表也直接显示各类异常次数。记录便捷列表直接以表格显示课程 / 类型、同学 / 学号和登记日期，不需要横向滑动查看这些字段。考勤卡片可勾选同学后批量登记，减号打开明细，可编辑、撤销和恢复。底部导航为 Android 系统安全区域留出空间。

手机登记的考勤可通过手机“数据与备份”导出 JSON，再在 Windows 版选择“合并手机考勤”。程序按工作台和考勤 ID 匹配，跳过完全重复记录；冲突显示两侧内容并默认保留 Windows，可逐条更改选择。合并不会因快照较旧而删除 Windows 记录。

“更新本机名单与课表”仍以 Windows 资料为准，并保留手机已有考勤；“合并手机考勤”不合并手机修改的学生或课程。若手机新增了班级、学生或课程，需要在电脑导入完整备份并选择“恢复为独立副本”，核对后使用该副本。更新手机资料前先导出备份，避免覆盖手机独有的资料修改。

备份 JSON 未加密，包含学生和考勤信息，请通过自己控制的 USB 或本地文件方式传递。Android 7.0 是最低系统版本。内部签名 APK 的构建环境、密钥保管和安装说明见 [Android APK 构建说明](Android%20APK%20构建.md)。

Ludian 0.5.4 继续读取此前版本的数据和备份，业务数据沿用 schema 3，原存储标识和数据目录保持不变。较早的 schema 1 / 2 在内存中兼容转换，第一次成功保存才写入 schema 3 快照，升级前的历史快照保留。为保护回收站状态，0.3.0 及更早程序会拒绝读取 schema 3 数据。

桌面版数据库默认位于 `%APPDATA%\cn.guilu.attendance\attendance.sqlite3`。SQLite 的 `-wal`、`-shm` 属于运行中的数据库文件，手工拷贝前先关闭应用。浏览器预览与桌面版数据独立，可通过完整 JSON 迁移。

任何本地存储都不能保证硬盘故障、误删或系统损坏时绝不丢失。程序采用事务和完整历史快照减少风险；可靠的外部备份仍然必要。如果启动提示数据损坏，不要删除或覆盖数据库，请先保留整个数据目录用于恢复。

## 主题、字体与交互

左上角只显示当前班级与学期，点击可切换、新建或管理工作台。顶栏左侧按钮用于收起 / 展开侧栏，悬停可查看提示；收起后按钮仍留在顶栏，重启后保留你的选择。

在“设置与偏好 → 外观与交互”中，视觉风格和明暗模式分别选择。

- **视觉风格**：内置 18 套宫崎骏风、二次元和国漫主题，并保留经典 Ludian 外观。点击缩略图查看预览，可切换预览浅色 / 深色；点击“应用主题”才更改界面，取消预览保持原选择。背景、配色、面板、按钮和装饰随主题变化，字体与字号继续使用你的设置。全部图片随程序提供，首次打开即可离线使用。
- **自定义主题**：在同一主题列表中上传自己的图片，或切换回任意内置主题、经典外观。每次只应用一套主题；切换时保留自定义图片，方便切换回来。旧版壁纸自动迁移为当前自定义主题。
- **玻璃透明度**：统一控制内置和自定义主题的底板透明度，范围 0–70%，数值越高，主题图片越明显；切换主题后保留设置。图片属于本机外观偏好，不进入考勤备份。
- **明暗模式**：可选 **跟随系统（默认） / 浅色 / 深色**。跟随系统时实时响应系统明暗变化；手动选择则固定所选模式。明暗效果覆盖课程表、数据库、弹窗、抽屉及桌面标题栏。方向键可在选择卡片间切换。

本版主题全部内置，不需要登录、开通云服务或下载主题包。

字体可以即时切换：

- **柔和圆体**：默认，轮廓圆润；源自 975 圆体。
- **手写文楷**：更自然的书写感；源自霞鹜文楷屏幕阅读版。
- **简洁黑体**：原 Noto Sans SC，清晰规整。
- **系统字体**：使用电脑自身界面字体。

前三种字体随应用离线提供，不需要另外安装。选择卡片会同时显示中文和数字样例。支持标准 / 舒适 / 大字三档字号，以及“恢复外观默认”。少见字自动回退其他可用字库。

按钮提供悬停、按下与键盘焦点反馈；图标有提示气泡，菜单 / 弹窗 / 详情抽屉使用短过渡，看板和列拖动显示落点。开启“减少动态效果”，或在系统中设置减少动态效果后，应用停止移动动画，保留高亮和文字提示。

外观偏好只在当前设备保存，不进入考勤快照或完整班级备份。升级到 0.5.0 时保留原明暗模式、字体、字号、动效和侧栏选择，初始使用经典视觉风格。浏览器预览与桌面版各自保存偏好。若偏好存储不可用，界面会提示改动仅本次生效，考勤仍按原方式保存。

Ludian 使用黑白 L 纸块图标，操作按钮按所选主题配色显示。字体来源和完整许可随软件提供，见 `FONT-LICENSE.txt`。

当前数据库围绕学生与考勤业务设计，支持上述五种视图和六类自定义属性；暂不包含 Notion 的公式语言、任意数据库关联、时间轴、在线协作与自动化。
