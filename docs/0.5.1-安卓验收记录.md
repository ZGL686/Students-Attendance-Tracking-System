## 变更

手机每日课表与整周切换、五项底部导航、全部功能菜单、工作台管理；学生 / 记录便捷列表和完整数据库；课程与学生编辑、名单与课表导入、批量考勤、明细编辑和撤销恢复、汇总与快照入口。弹窗、抽屉、输入与触控尺寸按手机适配。

Android 恢复完整离线 OCR/PDF 资源，生产输出包含 232 个离线文件、18 套 WebP 主题。前端资源通过 Tauri 嵌入 native library，不能仅凭 APK 缺少独立 `assets/index.html` 判断打包失败。

业务 schema 3、应用标识、SQLite 事务和历史快照格式未改动。手动同步的资料所有权仍以 Windows 为准；手机独有学生 / 课程须通过完整备份恢复为副本，不属于考勤合并范围。

## 仍待实机验收

没有连接可授权的实体手机；本机未报告可用的虚拟化加速。本轮没有运行 Android 模拟器。因此浏览器移动视口测试不等同于 APK 验收，以下事项尚未验证：

- 首次安装、0.5.0 → 0.5.1 覆盖更新、断网冷启动及 SQLite 重启持久化。
- Android 原生系统文件选择器读写备份、报表与课表文件。
- 系统返回键、软键盘、安全区域、不同 WebView 版本和低内存设备上的 OCR。
- 真实手机上 Windows ↔ Android 往返迁移及全部主题。

安装前导出完整备份；升级直接安装同签名 APK，不要先卸载。首次安装按手机提示允许当前文件来源安装应用。
