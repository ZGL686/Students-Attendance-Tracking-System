## 原生数据隔离与离线验收

测试分别使用单独的 Debug 构建和正式 `dist/Ludian-latest/Ludian.exe`，配合虚构数据、全新 `GUILU_DATA_DIR` 和 `WEBVIEW2_USER_DATA_FOLDER`。先校验实际数据与 WebView 目录，再执行界面操作；未使用真实用户数据库。

原生验收结果包含 `freshWebViewProfile: true`、`offlineChineseOcr: true`、`externalRequests: []`、`builtinThemePackPersisted: "sky-hill"` 和 `revisions: 12`。该结果表明新配置下首次中文 OCR 可用，本次运行没有观察到外部请求，主题与保存修订经重启核实。

已通过实际原生界面验证：旧数据 schema 读取与成功保存后迁移、原快照与历史字段保留、JSON 备份保存、离线中文 OCR 导入保存及重启、主题与离线字体应用和持久化。业务 schema 继续为 3，应用标识、存储目录、SQLite / IndexedDB 身份和备份身份保持兼容。

最终解压版独立重复全部原生功能验收，通过旧数据迁移、离线首次 OCR、保存、历史快照保留及重启恢复。另以普通启动方式运行同一 EXE，不设置调试参数；确认窗口标题为 `Ludian · 班级考勤`、WebView 目录隔离、没有远程调试参数或监听端口，并正常关闭，退出码为 0。自动化用的调试参数由测试脚本临时传入，没有写进发行配置。

## 界面与可读性检查

虚构班级、课程、考勤和备忘用于三组截图：青空之丘浅色完整课表、霓虹都市深色考勤、包含 18 套主题及经典外观的完整图库。逐张查看后，卡片和文字布局正常；图库 19 张卡片没有内容裁切，图库和考勤页面没有横向溢出。

课表实际容器 `.calendar` 和考勤表格使用实色主题表面，背景插画不会透过表格正文。18 套主题在浅色与深色下的正文、次要文字、表格灰字、侧栏文字和主按钮文字对比度检查均至少为 4.5:1。考勤类型与课程语义色保留原定义。
