# Ludian · 班级考勤

面向 Windows 桌面与 Android 手机的本地班级考勤应用。使用 React、TypeScript、Vite 和 Tauri 2，提供周课表、异常考勤登记、多工作台、学期汇总与备份迁移。

当前源码、Android APK 与 Windows EXE / ZIP 统一更新为 **0.5.12**。本版补齐各页面阅读卡片、工具区和说明文字的内边距，手机备份操作改为单栏，避免文字贴边及按钮拥挤。保留主题、玻璃透明度、明暗、字体和字号偏好；底部导航继续避开系统区域。手机 Excel / CSV 选择后自动追加保存，桌面继续支持图片与 PDF，本地数据和历史考勤保留。实际版本及 SHA-256 见发行目录中的版本文件。

保留表格、看板、画廊、列表、日历、保存视图、自定义属性、筛选排序、批量编辑和关联汇总。更名不会改变原数据目录、备份格式或已有记录。

## 使用

Windows **0.5.12** 发行包可直接打开 `dist/Ludian-latest/Ludian.exe`，或将 `dist/Ludian-latest.zip` 解压后运行。运行环境为 Windows 10/11 x64，需要 Microsoft Edge WebView2 Runtime；实际产物版本及 SHA-256 以 `dist/Ludian-latest/version.json` 为准。

- 课程表按北京时间显示当前周，支持周次切换、课程详情、添加和编辑课程；每天最多 10 节、学期最多 30 周，支持不连续周和单双周。
- 手机和手机模拟器的“导入课程”接受 `.xlsx`、UTF-8 `.csv`，可一次选择多份文件。Excel 默认处理全部工作表；列表包含课程名称、星期、节次和周次，网格按顶部星期与左侧节次读取合并课程格。整批读取完成后，有效安排通过一次事务追加保存；重复、缺失或冲突项显示原因，已有课表、学生及历史考勤保留。
- 误选学生名单会提示到“学生”页导入；空表、没有课程信息、只有目录或缺少字段分别提示。混合工作表中的有效课程仍可导入。网格未标周次时使用保存事务中最新的学期总周数，非网格列表需提供周次。手机无需 OCR 或额外插件。
- 桌面继续支持 PNG、JPEG、WebP、BMP 和 PDF 本地导入。图片名称、星期或节次不可靠时跳过，教师或教室不可靠时留空并提示；目录图片只作为当前窗口的临时参考资料，不会单独保存为课程。
- 在“外观与交互”中预览 18 套宫崎骏风、二次元、国漫主题，也可使用经典外观或导入自己的壁纸。壁纸压缩后保存在设备偏好中，玻璃透明度可调；明暗模式、字体、字号和减少动效分别设置。
- 文字颜色和阅读底板随主题自动配合；背景干扰较强时，文字所在区域会自动更实，周围仍显示所选壁纸。通知、提示和禁用按钮采用各自的可读配色；已撤销记录保留文字与状态标记。无需手动选择文字颜色。
- 点击学生对应类型下的 `+`，登记一次请假、旷课、迟到或早退。每条记录保存日期、时间、课程快照与备注。
- 支持批量登记、补记、查看个人明细、修改、撤销和恢复。统计异常登记次数，未登记不代表已确认出勤。
- 汇总可以按日期及课程筛选，导出 Excel（汇总、明细两个工作表）或 Markdown。
- 导入包含“姓名”“学号”列的 `.xlsx` 或 UTF-8 `.csv`，创建独立工作台。第一张工作表用于名单导入，重复学号或缺失信息会阻止导入。
- 在“学期设置”中随时修改开学日期、作息、总周数、备忘与新增考勤类型。
- 在“数据与备份”中导出完整 JSON；恢复先校验 SHA-256 和数据结构，再创建独立副本，保留已有工作台。

Android **0.5.12** 面向 Android 7.0 及以上 ARM64 / ARMv7 手机，安装入口为 `dist/Ludian-Android-universal.apk`，实际产物版本及 SHA-256 以 `dist/android-version.json` 为准。更新前先导出完整 JSON 备份至应用外；已安装同签名 **0.5.3–0.5.11** 时可直接覆盖安装，保留原本地数据，不要先卸载。课程导入仅接受 Excel / CSV；实体手机覆盖安装、文字显示、底部导航和重启保存仍待验收。底部为课表、考勤、学生、记录、备份，右上角“全部功能”可进入汇总、设置和工作台管理。手机与 Windows 通过手动 JSON 备份迁移，不提供云同步。构建与签名见 [Android APK 构建说明](docs/Android%20APK%20构建.md)。

完整操作说明见 [使用说明](docs/使用说明.md)。

## 开发

建议 Node.js 24 LTS（质量检查至少需要 22.13+）、Rust MSVC、Visual Studio C++ Build Tools、Windows SDK 和 WebView2。依赖锁定在 `package-lock.json` 和 `src-tauri/Cargo.lock`。

```powershell
npm ci
npm run dev
# http://127.0.0.1:15473
npm run desktop:dev
npm run check
npm test
npm run test:e2e
cargo test --manifest-path src-tauri/Cargo.toml --lib
npm run test:native
npm run release
```

浏览器测试默认使用本机 Microsoft Edge。Vite 固定为 15473 端口，并忽略 Rust 构建目录，避免 Windows 文件占用导致监听失败。

### 浏览器手机模拟器

运行 `npm run dev` 后打开 [手机模拟器](http://127.0.0.1:15473/phone-simulator.html)。它嵌入真实应用，默认显示“水墨江南”浅色主题的课程表工作台，底部从左到右为课表、考勤、学生、记录、备份。

Windows 也可双击项目根目录的 `启动手机模拟器.cmd`。等待终端出现 `VITE ready` 后打开上述地址，使用期间保留终端窗口；服务已运行时，入口会提示复用现有服务。关闭终端、退出运行服务的工具或重启电脑后，开发服务器会结束，需要重新启动入口再刷新网页。浏览器自动恢复标签页不会自动启动服务器，`ERR_CONNECTION_REFUSED` 表示该地址没有可连接的服务。

- 根据用户提供的 REDMI Turbo 4 Pro（6.83 英寸、1280×2772、HyperOS 2、三按钮导航）保留屏幕比例，默认网页视口为 **400×866 CSS px**。这是可调的预览参数；真实 CSS 视口取决于手机显示密度设置。
- 三按钮模式模拟 **48px** 底部系统区，手势模式为 **24px**。应用结合系统与模拟安全区保留底部留白，导航图标和文字整体放在系统区域上方；真实 Android 的系统区域由设备实际 Insets 决定。
- 可调整宽高、旋转屏幕、切换自动适应或 100% 尺寸。窄浏览器中点击“模拟设置”展开控制；自动适应显示整机，100% 模式支持在预览区滚动。
- 预览使用独立的 `ludian-phone-simulator` IndexedDB、外观偏好和 Android 导入标记；首次创建示例课程，学生名单初始为空。旧预览中的默认示例同学会自动清理并保留原快照，手动添加及已更名 / 改学号的学生继续保留。修改刷新后保留，普通网页和桌面数据不进入模拟器。
- 修改应用源码后 Vite 会热更新。模拟器入口用于本地开发；`npm run build` 继续构建普通应用，不把演示入口放入 Windows / Android 发行页面。

模拟器验收：`npx playwright test tests/e2e/phone-simulator.spec.ts`。浏览器系统栏是布局占位，不替代 Android APK 实机验收。

手机模拟器沿用 Android 的 Excel / CSV 导入限制，不能用桌面图片识别成功代替手机验收。表格读取逐工作表判断学生名单、空表、仅目录、缺少字段及有效课程；整批有效安排合并后一次保存。相关资源、流程与数据保护约定见 [架构与交互规范](docs/架构与交互规范.md)。

桌面批量图片 / PDF 识别沿用 Tesseract.js 中文 / 英文 OCR 与 PDF.js 离线资源。`tests/e2e/timetable-colored-ocr.spec.ts` 使用虚构目录和彩色课表核对课程、星期、节次和教室；`timetable-import-batch.spec.ts` 检查目录暂存及批量保存边界。桌面可混选图片、Excel、CSV、PDF，进度按整个批次累计；单个 OCR 任务超过 45 秒未响应会终止并提示，可取消。文件只在本机处理。

桌面验收使用 Node 内置 SQLite 创建虚构学生的旧版快照，单独构建 Debug 版本，并用本机 9333 调试端口连接 WebView2。同时隔离 SQLite 和 WebView2 缓存，写入前校验实际目录。验证升级、旧快照保留、新视图、三种离线字体、侧栏收展、主题 / 字体 / 字号 / 动效偏好、工作台回收站、考勤减号与恢复、原生保存对话框及退出重启。测试完成关闭应用；发行版不会开启此端口。

## 本地名单与仓库边界

公开源码不包含真实学生姓名、学号、考勤数据或个人备份。无本地名单时，源码首次启动提供预置课表及空名单，可在应用里新建工作台导入名单。需要构建个人版时：

```powershell
npm run roster:seed -- "你的班级信息表.xlsx"
npm run release
```

`public/local-seed.json`、`dist/`、`web-dist/`、`.local/` 和数据库均被 Git 忽略。个人版会把本地名单嵌入可执行文件，分发应用即包含名单，请按使用范围保管。初始化仅在数据库完全为空时运行，任何版本更新都不得重新覆盖名单或考勤。

## 数据保存

桌面版通过 Tauri 命令写入 `%APPDATA%/cn.guilu.attendance/attendance.sqlite3`，界面显示实际绝对路径。数据库与程序解压目录分离。SQLite 使用 WAL、FULL 同步和事务；每次写入增加一个完整快照，以版本号拒绝过期写入。单实例插件避免桌面程序重复开启。

浏览器版使用 IndexedDB 的事务快照，与桌面数据互相独立。可以用 JSON 完整备份迁移。界面只有在保存成功后才更新计数；失败会显示错误，原数据不替换。

同一磁盘上的快照不能抵御磁盘故障，因此仍需定期把完整备份保存到其他可靠位置。所有快照保留，长期大量登记时数据库会增长；首版没有自动清理历史。SQLite 文件存在损坏时不自动重建或覆盖。

数据 schema 现为 3；版本 1 / 2 在内存中兼容升级，首次成功写入才产生版本 3 快照，原快照保留。新版备份包含回收站及所有视图、属性与单元格。旧程序会拒绝读取新版数据，避免静默丢弃新字段。

支持通过 `GUILU_DATA_DIR` 指定绝对数据目录用于隔离验收；日常使用无需设置。桌面测试还必须通过 `WEBVIEW2_USER_DATA_FOLDER` 隔离浏览器缓存 / 偏好，使用 `.local/` 内的新目录，并校验 WebView 子进程的实际路径。不允许触碰真实用户数据库。Tauri JSON 的 `dataDirectory` 只接受相对路径，不能用绝对路径代替此运行时隔离。

## 初版边界与依据

初始课表依据用户提供的 2026–2027 第一学期课表和四张截图。开学日期初始为截图中的 2026-09-07，可随时修改；第 9–10 节部分时间为可编辑初始值。只有周次、没有日期节次的实践课程列入备忘，不自动排课。课程支持不连续周次，如 `1-2,4-13`，以及 `1-16单周`、`1-16双周`。

课表导入面向常见课程列表和按星期、节次排列的网格。手机只读取 Excel / CSV 的结构，不识别图片或 PDF；桌面保留本地图片 / PDF OCR。名称、星期及完整节次必须明确，教师和教室可为空。网格缺周次时使用最新学期全周并提示；非网格列表缺周次时跳过并提供补录。单个文件不超过 20 MB；旧 `.xls` 需另存为 `.xlsx`。桌面图片不超过 2400 万像素、PDF 不超过 50 页。取消或整批读取失败不会修改课表，保存失败保留原数据。业务数据继续使用 schema 3。

界面和数据库行为参考 Notion 官方多张产品截图与 [视图、筛选和排序手册](https://www.notion.com/help/views-filters-and-sorts)。来源、实际映射和实现边界见 [设计参考](docs/设计参考.md)。Tauri 环境依据 [官方 Windows 前置条件](https://v2.tauri.app/start/prerequisites/)。

历史验收记录见 [0.4.0 验收](docs/验收记录-0.4.0.md)，前版记录保留。模块边界、质量命令和交互约定见 [架构与交互规范](docs/架构与交互规范.md)。内置字体遵循 SIL OFL 1.1，许可与来源见 [字体说明](public/fonts/README.md)。

首版为单机异常考勤管理，不含多设备同步、完整逐堂点名/出勤率、学校系统自动抓取或自动更新。程序未做商业代码签名。

远程仓库：[ZGL686/Students-Attendance-Tracking-System](https://github.com/ZGL686/Students-Attendance-Tracking-System)。每次完整修改需更新工程日志、完成相关检查、提交并推送。
